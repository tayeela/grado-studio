# ГРАДО 2

Рабочее место градостроителя: от границы территории до пакета материалов за один рабочий день.

- карта существующего положения из реальных источников (ГИС ОГД, ЕГКО, НСПД, OpenStreetMap, Яндекс) с датой каждой выгрузки;
- ограничения (ЗОУИТ, красные линии, ПЗЗ), эскиз застройки и ТЭП по нормам Москвы;
- альбом «План реализации ППТ КРТ» в PDF и PPTX (А3, шапка и условные обозначения по образцам владельца), обмен с AutoCAD (DXF) и QGIS;
- совместная работа над проектом на сайте.

Программа состоит из маленького сервера на Python и страницы в браузере. Данные остаются на вашем компьютере.

## Запуск

| как | что сделать |
|---|---|
| macOS | двойной клик по `ГРАДО 2.command` |
| Windows | двойной клик по `ГРАДО 2.bat` или установщик из GitHub Actions |
| из исходников | `python3 apps/grado2/server.py` и открыть <http://localhost:8650> |
| сайт | <https://grado.tailink.tech> (доступ выдаёт владелец) |

Подробно — [docs/guides/install.md](docs/guides/install.md). Проверка кода: `tools/gate.sh` (с браузерными сценариями — `E2E=1 tools/gate.sh`).

## Как мы работаем

Источник правды — GitHub: задачи и слова владельца — в Issues, работа — ветка и PR в `team/t60`, на сайт — слиянием `team/t60 → main` по слову владельца
«выкладывай». Каждый PR проходит тесты и проверку документов; вики в `docs/wiki` пересобирается из кода сама.
Порядок команды — [docs/team/CYCLE.md](docs/team/CYCLE.md), правила для ИИ-агентов — [CLAUDE.md](CLAUDE.md) и [AGENTS.md](AGENTS.md).
