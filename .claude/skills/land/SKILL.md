# Выкладка («выкладывай»)

Только по слову владельца в чате. Порядок — `docs/team/CYCLE.md`, раздел Landing; коротко:

1. Основная копия `~/grado-studio`: `git status --porcelain -- apps/grado2 core docs` пустой; иначе — стоп и сказать владельцу.
2. В рабочей копии команды (`.claude/worktrees/team2`, ветка `team/t60`): `git merge main` (конфликты в docs/team —
   объединить обе стороны), затем `E2E=1 tools/gate.sh` — зелёный.
3. Основная копия: `git merge --ff-only team/t60` — хук обновит сайт; прочитать вывод («Готово: на сервере версия …»;
   «отложено» или ошибка — старая версия работает, повторить `tools/deploy-server.sh` позже).
4. `git push origin main team/t60`. В `docs/team/BOARD.md` перенести «Готово к выкладке» в «Сделано и выложено»,
   строку в `docs/team/PROGRESS.md`, отметку в `docs/team/OWNER.md`; коммит с `GRADO_NO_DEPLOY=1`.
5. Владельцу: версия, что изменилось на экране, результат сервера, «перезапустите программу, чтобы увидеть».
