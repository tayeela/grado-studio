# apps/grado3 — новый интерфейс ГРАДО

Интерфейс, собираемый заново по плану [docs/product/plan-2026-11-09-frontend-rust.md](../../docs/product/plan-2026-11-09-frontend-rust.md)
(шаги И1–И6). Живёт рядом с нынешним (`apps/grado2/ui`, адрес `/next/`) и открывается по адресу **`/g3/`** того же
сервера ГРАДО 2. Адрес сайта переключится на него только после всех сценариев приёмки (шаг И6).

| файл или папка | что это |
|---|---|
| `ui/src/main.ts`, `ui/src/App.vue` | вход и каркас окна: строка пяти шагов, окна рабочего места (dockview), командная строка, строка состояния |
| `ui/src/workspaces.ts` | пять рабочих мест: Территория, Данные и оформление, Проект, Виды и листы, Выдача |
| `ui/src/commands/` | шина команд (`bus.ts`): любое действие — команда с отменой; команды каркаса (`builtin.ts`) |
| `ui/src/stores/` | Pinia: проект — один документ (`project.ts`), окно (`ui.ts`), команды (`commands.ts`) |
| `ui/src/core.ts`, `ui/src/wasm/` | ядро Rust в WebAssembly: координаты МСК и проверка файла проекта (собирает `tools/build_core_wasm.sh`) |
| `ui/src/types/` | типы TypeScript проекта, построены из Rust (`rust/crates/model`, ts-rs); руками не правят |
| `ui/src/panels/` | окна каркаса: карта, слои, проект, проверка, заглушки окон следующих шагов |

Сборка: `cd apps/grado3/ui && npm ci && npm run build` → `apps/grado2/web/g3/` (лежит в репозитории, как `/next/`).
Проверка: `tools/ui3_check.sh` (типы, тесты Vitest, свежесть сборки); её зовёт `tools/gate.sh`.
Замер скорости против нынешнего интерфейса: `node tools/ui_baseline.mjs`.
