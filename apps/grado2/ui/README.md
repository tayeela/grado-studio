# apps/grado2/ui — исходники нового интерфейса

Новый интерфейс ГРАДО 2 на готовых ядрах (решение владельца 08.10.2026, `docs/product/engine-map.md`):
Vue 3, dockview (окна и панели), Web Awesome (кнопки, меню, формы), OpenLayers (карта), значки Lucide, SortableJS (перетаскивание), Tabulator (таблица атрибутов), Turf (геометрия границы).
Переносим экран за экраном; пока это страница `/next/index.html` (окна «Слои», «Свойства», «Объект», «Таблица атрибутов», «Виды», «Справка», «Данные», «Ограничения», «Схема расчёта», «Проект» и выгрузка DXF и GeoJSON перенесены, проект сохраняется в тот же файл), рабочая страница `web/index.html` не меняется.

| файл | что это |
|---|---|
| `package.json`, `package-lock.json` | точные версии библиотек |
| `vite.config.js` | сборка в `../web/next/` (лежит в репозитории: Node на Mac, сервере и в установщике не нужен) |
| `index.html`, `src/main.js` | вход страницы, подключение библиотек и окон |
| `src/App.vue` | каркас: шапка с меню, лента инструментов, окна dockview, строка состояния |
| `src/store.js` | общее состояние: группы, слои и виды проекта, текущий слой, тема, подложка, масштаб |
| `src/project.js` | проект через API рабочей программы: открыть, сохранить, сохранить как, новый, файл с диска и на диск, автосохранение |
| `src/constraints.js` | расчёт ограничений как в рабочей странице: запреты (ЗОУИТ, красные линии, пожарные разрывы, ПЗЗ, Генплан) и инсоляция с предельной высотой; «Проверить нормы» эскиза |
| `src/data.js` | данные: граница территории, область загрузки, выгрузка источников с перевыгрузкой, импорт файлов |
| `src/graphfile.js`, `src/graph_default.json` | схема расчёта в файле проекта (вид litegraph, как у рабочей страницы): типы блоков, схема по умолчанию, приведение старых схем |
| `src/graph.js` | расчёт блоков схемы по связям с кэшем и правка схемы (блок, связь, поле, удаление, «В слой») |
| `src/graphmap.js` | результат схемы на карте: пятно застройки, эскиз, резерв участков соцобъектов, выход выбранного блока |
| `src/variants.js` | окно «Варианты»: подбор вариантов (типология × ширина × поворот, этажность под цель плотности), сохранённые варианты в блоке ТЭП |
| `src/maplayers.js` | подложка и слои проекта на карте OpenLayers — общее для «Карты» и двух карт «Сравнения» |
| `src/sketch.js` | окно «Эскиз»: параметры блоков в окне, «Построить эскиз», «Сохранить слоем», резерв участков ДОО, школы, поликлиники, цель по ПЗЗ |
| `src/sketchgen.js` | генератор посадки застройки (типологии, разрывы, малоэтажные ряды, урбан-блоки, цель плотности) |
| `src/tep.js` | показатели: параметры территории, запрос ТЭП к серверу, нормативы, резерв участков соцобъектов |
| `src/edit.js` | правка слоёв и групп (создать, удалить, переместить, сгруппировать) и общая отмена Ctrl+Z |
| `src/exports.js` | меню «Выгрузка»: чертёж DXF и GeoJSON в МСК через сервер |
| `src/geom.js` | геометрия для расчётов: перевод в метры и обратно, объединение, разность, буфер, площадь в МСК |
| `src/features.js` | объекты слоёв: выбор, площадь и длина в МСК, правка атрибутов, новое поле, удаление |
| `src/symbology.js` | оформление слоёв как у рабочей страницы: категории, диапазоны, правила, ЛГР, штриховка, подписи, масштаб |
| `src/theme.css` | плотная тема, светлая и тёмная, цвета окон dockview |
| `src/panels/*.vue` | окна: «Карта», «Слои», «Свойства», «Объект», «Таблица атрибутов», «Данные», «Ограничения», «Схема расчёта» (Rete.js; блок — `GraphNode.vue`), «Эскиз», «Показатели (ТЭП)», «Нормативы расчёта», «Варианты», «Сравнение», «Объём», «Виды», «Справка» |

Сборка после правки: `cd apps/grado2/ui && npm ci && npm run build`, затем закоммитить и исходники, и `web/next/`.
Свежесть сборки проверяют `tools/ui_check.sh` (шаг `ui` в `tools/gate.sh`) и CI.
