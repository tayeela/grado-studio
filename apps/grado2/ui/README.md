# apps/grado2/ui — новый интерфейс ГРАДО 2 (Vue 3 + Konva, сборка Vite)

Решения владельца 08.10.2026 (ответы «1а 2б 3а 4а» к карте замен): интерфейс переходит на Vue 3 + dockview + Web Awesome
со сборкой Vite, редактор раскладки листов — свой, на Konva. Здесь живёт новый код; нынешняя страница `../web/` работает
как раньше и этой папки не видит. Первым сюда пришёл редактор раскладки листа (шаг 2 плана); каркас окон (шаг 3) встанет рядом.

## Что внутри
Редактор устроен как «Макет» QGIS: слева «Элементы» (глаз, замок, переименование), в середине лист с линейками
и направляющими, справа «Свойства», сверху лента, снизу строка состояния с координатами курсора в мм.

| файл | что это |
|---|---|
| `src/sheet/model.js` | модель листа: формат А4–А0, ориентация, рамка и штамп по ГОСТ, направляющие, сетка, элементы в мм листа; масштаб и охват карты, замечания, смена формата, выравнивание, распределение, порядок, копии, опорная точка, привязка |
| `src/sheet/stamp.js` | линии и тексты основной надписи 185×55 — те же, что рисует печать (`core/layout/grado_layout/frames.py`, `StampFrame`) |
| `src/sheet/draw.js` | рисование элементов на Konva: карта (пока заглушка), легенда, надпись, картинка, стрелка севера, масштабная линейка, таблица, прямоугольник, эллипс, линия |
| `src/sheet/SheetEditor.vue` | редактор: лист, линейки, направляющие, выбор рамкой и с Shift, перетаскивание с привязкой (`../web/snap.js`), ручки размера и поворота, клавиши, выгрузка PNG 300 dpi; лист — через `v-model` |
| `src/sheet/Ribbon.vue`, `ItemsPanel.vue`, `PropsPanel.vue`, `NumField.vue` | лента, панель «Элементы», панель «Свойства», числовое поле со степпером |
| `src/sheet/model.test.js` | проверки модели (`node --test`); их же запускает `../tests/test_sheetmodel_js.py` в `tools/gate.sh` |
| `src/main.js`, `index.html` | пробная страница: лист А3 с картой, легендой и штампом |
| `vite.config.js`, `package.json` | сборка; библиотеки Vue 3, Konva, Vite (MIT), значки lucide-vue-next (ISC), версии закреплены |

## Запуск
```
cd apps/grado2/ui && npm ci && npm run dev      # пробная страница: http://localhost:5173
npm test                                         # проверки модели листа
npm run build                                    # сборка в dist/ (в репозиторий не кладётся); её же делает tools/gate.sh
```

## Что дальше
- Карта в блоке «Карта» — пока заглушка с масштабом и охватом на местности. Следующий шаг — OpenLayers с точным масштабом
  внутри блока или SVG листа с сервера (`/api/print/svg`), как в нынешнем «Макете листа» (`../web/layout.js`).
- Перенос листа в печать: блоки модели → прямоугольники карты и колонки в `print_io.layout()`; пока печать строит раскладку сама.
- Правила альбома (`docs/wiki/album-rules.md`) остаются в печати; редактор их не меняет.
