# apps/grado2 — рабочая программа

Читайте [README.md](README.md) (карта файлов), для функций — [../../docs/wiki/modules.md](../../docs/wiki/modules.md), для маршрутов — [../../docs/wiki/api.md](../../docs/wiki/api.md).

- Сервер — Python (стандартная библиотека + `requirements.txt`), страница — без сборки (OpenLayers, turf, litegraph лежат в `web/vendor/`).
- Правка сервера требует перезапуска, правка страницы — перезагрузки; тестовый сервер — порт 8651 и выше, проекты — только копии.
  Порт 8650 и «Документы/ГРАДО 2» — рабочие данные владельца: никогда не использовать в тестах.
- Перед коммитом `tools/gate.sh` (`E2E=1`, если менялись страница, печать или альбом); версия в `web/version.json` и запись сверху
  `../../docs/grado2-changelog.md`.
- Альбом: сначала [../../docs/wiki/album-rules.md](../../docs/wiki/album-rules.md); картинку проверяют глазами (железное правило 6).
- Файл кода начинается с заголовка «что это» ([../../docs/CLAUDE.md](../../docs/CLAUDE.md)); тест для нового поведения кладут рядом (`tests/`).
- Маршрут по id слоя, а не по первому слою вида (железное правило 5). Тексты ошибок сервера — только ASCII.
- Закрытые `apps/studio`, `apps/wizard`, `apps/calc-web` не править.
