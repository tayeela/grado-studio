С чего начать
  1. Создайте слой — кнопка + в панели «Слои» справа (выберите геометрию: точка / линия / полигон).
  2. Слева выберите инструмент (Полигон, Линия, Точка).
  3. Чертите на холсте — объект идёт в активный слой.

Или сразу: Демо — пример проекта · НСПД/ОГД — импорт данных.
