# Контрольные строки альбома

Здесь лежат строки текста, которые должны (или не должны) быть в готовом альбоме. Это постоянный тест на слова владельца: «адрес по письму ДГП», «на ортофотоплане
выноска “Проектируемая территория – N га”», «сноску не печатать». Строки проверяет `tools/album_lint.py` (код `expect`) по тексту PDF и PPTX; `tools/album_check.py --name gol`
подхватывает `all.json` и `<имя территории>.json` сам, и красная строка отчёта останавливает приёмку (код выхода 3).

| файл | для чего |
|---|---|
| `all.json` | любой альбом: запрещённые формулировки |
| `mytishchi.json` | Новый набор #167: формулировка доступности. Число физических страниц берётся из PrintSpec; адрес и выноски территории сохраняются из её ожиданий. Старый альбом по-прежнему проверяет фиксированные 11 страниц. |
| `gol.json` | КРТ 3229, район Гольяново: число листов, адрес титула, выноски территории |

## Формат

```json
{
  "_": "пояснение (ключи на «_» пропускаются)",
  "pages": 11,
  "require": [{"text": "строка", "pages": [3, 4], "each": true, "why": "откуда правило"}],
  "forbid":  [{"re": "регулярное выражение", "pages": [1], "sev": "warn", "why": "откуда правило"}]
}
```

- `text` — подстрока; `re` — регулярное выражение (одно из двух). Пробелы любого вида (в том числе неразрывные) и переводы строк сравниваются как один пробел.
- `pages` — номера страниц выдачи; без него — любая. `each: true` в `require` — строка нужна на каждой из перечисленных страниц, иначе достаточно одной.
- `sev` — `error` (по умолчанию) или `warn`. `why` — обязательна: тест не пропустит строку без причины.
- `pages` на верхнем уровне — сколько страниц должно быть в альбоме.

## Как пополнять

1. Владелец назвал конкретный текст («пиши вл. 8», «выноска такая») — строка в `require` или `forbid` ставится в тот же коммит, где правило попадает в свод (навык `owner-remark`).
2. Аудит нашёл пропущенную строку — так же, с номером причины в `why`.
3. Строку снимают только вместе со снятием правила в `docs/wiki/album-rules.md` (раздел «Снятые и изменённые правила»).
4. Проверка строк: `python3 tools/album_lint.py album.pdf --pptx album.pptx --expect tools/album_expect/all.json --expect tools/album_expect/gol.json`.
