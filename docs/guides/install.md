# Запуск ГРАДО 2

ГРАДО 2 — это небольшой сервер на вашем компьютере и страница в обычном браузере (адрес `http://localhost:8650`).
Данные никуда не уходят: сервер слушает только этот компьютер; интернет нужен для карт-подложек и выгрузки данных с порталов.

## Mac и Windows — двойной клик

| система | файл в корне репозитория | где живёт окружение |
|---|---|---|
| macOS | `ГРАДО 2.command` | `~/.grado2/venv` |
| Windows | `ГРАДО 2.bat` | `%LOCALAPPDATA%\GRADO2\venv` |

Первый запуск сам создаёт окружение и ставит зависимости из `apps/grado2/requirements.txt` (ezdxf, certifi, pillow): нужны интернет
и Python 3.10 или новее с python.org. Следующие запуски открывают браузер за несколько секунд.

## Установщики

Сборка установщиков — в GitHub Actions, задача `build` файла `.github/workflows/grado2-release.yml`: запускается по тегу `grado2-v*`
и вручную (Actions → «ГРАДО 2 release» → Run workflow). Результат — установщик Windows (`.exe`, Inno Setup) и образ macOS (`.dmg`).
Как собрать самому — [../../packaging/README.md](../../packaging/README.md).

## Из исходников

```sh
python3 apps/grado2/server.py            # порт 8650
python3 apps/grado2/server.py 8651       # другой порт
python3 apps/grado2/server.py --hub      # совместный режим (аккаунты и проекты на сервере)
```

Переменные окружения и устройство программы — [../../apps/grado2/README.md](../../apps/grado2/README.md).
Проекты по умолчанию лежат в `Документы/ГРАДО 2` (переменная `GRADO2_PROJECTS` меняет папку). Тесты запускайте только на копиях проектов
и на другом порту: порт 8650 и эта папка — рабочие данные владельца.

## Сайт

Рабочая копия для совместной работы — <https://grado.tailink.tech> (сервер `msk`; доступ выдаёт владелец).
Сайт обновляет сам сервер: раз в 5 минут он забирает ветку `main` с GitHub ([../../tools/server_pull/README.md](../../tools/server_pull/README.md),
рецепт — [../wiki/recipes.md](../wiki/recipes.md)).

## Данные порталов

- ГИС ОГД, ЕГКО, OSM (Overpass), Яндекс — работают без настройки.
- НСПД требует корневые сертификаты Минцифры в `~/.grado2/ca/` — какие и откуда, написано в
  [../../core/connectors/grado_connectors/certs/README.txt](../../core/connectors/grado_connectors/certs/README.txt). Проверку сертификатов отключать нельзя.
- Из облачных сессий НСПД недоступен напрямую; для них есть релей на российском сервере — [../../tools/nspd_relay/README.md](../../tools/nspd_relay/README.md).

## Если что-то не запускается

Найдите ниже то, что видите на экране. Шаги везде одни и те же: что на экране → что сделать → что должно получиться.

### Окно просит Python

1. **На экране.** Окно пишет «Первый запуск: готовлю окружение…», затем «Нужен Python 3.10+ с python.org» и ждёт нажатия клавиши.
2. **Что сделать.** Поставьте свежий Python с <https://www.python.org/downloads/> (3.10 или новее). Закройте окно и запустите
   «ГРАДО 2.command» / «ГРАДО 2.bat» ещё раз.
3. **Должно получиться.** Окно снова напишет про первый запуск, поставит зависимости (несколько минут) и откроет браузер с программой.

Python мог стоять на компьютере и раньше, просто старый: установленный с python.org ставится рядом и ничего не ломает.
Если после установки ошибка осталась — смотрите сценарий «Установка не докачалась».

### Mac: «не удаётся проверить разработчика»

1. **На экране.** macOS сообщает, что «ГРАДО 2.command» (или приложение из установщика) нельзя открыть, так как не
   удаётся проверить разработчика.
2. **Что сделать.** Щёлкните файл правой кнопкой мыши (или с зажатым Control) → «Открыть» → в появившемся окне ещё раз
   «Открыть». Достаточно сделать это один раз.
3. **Должно получиться.** Файл запустится, дальше — обычный первый запуск.

Это защита macOS для файлов «из интернета»: установщики ГРАДО 2 не подписаны сертификатом разработчика, поэтому
предупреждение — не поломка.

### Установка не докачалась

1. **На экране.** В окне — ошибка со словами `ModuleNotFoundError` или `No module named` (на Windows окно может просто
   мелькнуть и закрыться).
2. **Что сделать.** Проверьте интернет. Увидеть ошибку целиком: на Mac перетащите «ГРАДО 2.command» в Терминал и нажмите
   Enter; на Windows перетащите «ГРАДО 2.bat» в окно «Командной строки» и нажмите Enter. Если ошибка остаётся, удалите
   папку окружения — Mac: `~/.grado2/venv`, Windows: `%LOCALAPPDATA%\GRADO2\venv` — и запустите файл двойным кликом:
   окружение соберут заново.
3. **Должно получиться.** «Первый запуск: готовлю окружение…», затем браузер с программой.

Первый запуск качает зависимости из интернета; если связь оборвалась на середине, окружение остаётся неполным —
с нуля оно собирается без следов старого.

### Окно пишет про порт

ГРАДО 2 занимает порт 8650; если он занят другой программой, сама переходит на ближайший свободный — 8651, 8652 и так
далее. Настоящий адрес всегда в окне: строка «ГРАДО 2: http://127.0.0.1:порт».

| сообщение в окне | что сделать | что должно получиться |
|---|---|---|
| «ГРАДО 2 уже работает: http://127.0.0.1:…» | ничего; браузер откроется сам, иначе наберите этот адрес | программа открыта |
| «…работает прежняя версия ГРАДО 2 — заменяю её новой» | ничего, подождите несколько секунд | свежая версия поднимется и откроется |
| «На порту … работает старая версия ГРАДО 2. Остановите её (Ctrl+C в её окне)…» | найдите окно старой копии (в нём строка «ГРАДО 2: http://…»), нажмите в нём Ctrl+C и запустите заново | обычный запуск |
| «порты 8650–8669 заняты» | закройте лишние окна с запущенными копиями ГРАДО 2 и запустите снова | обычный запуск |

### Браузер не открывает страницу

1. **На экране.** Браузер пишет, что не может открыть страницу, или открытая программа перестала отвечать.
2. **Что сделать.** Программа работает, пока открыто её окно: закрыв окно, вы её выключаете. Окна нет — запустите ГРАДО 2
   заново. Окно есть — наберите в браузере адрес из строки «ГРАДО 2: http://127.0.0.1:порт» и обновите страницу.
3. **Должно получиться.** Программа открывается.

Если сервер при старте пишет про `GRADO2_PUBLIC_HOST` и ключи доступа — это публичная копия (см. «Сайт» выше); сообщение
само перечисляет, какого ключа не хватает.
