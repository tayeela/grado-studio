# ТЗ на пользовательский интерфейс «ГРАДО Студии»

Версия 1.0 · опорная реализация: apps/studio v0.8 · UX-референс: rayon.design
Статус пунктов: [есть] — реализовано, [дораб] — реализовано частично,
[план] — целевое требование.

## 1. Назначение и принципы

Инструмент градостроителя для этапов «анализ существующего положения →
АГК → ППТ»: черчение планировочных решений поверх открытых данных с
живым расчётом ТЭП и выпуском документов. Принципы:

1. Одна модель — все представления. Холст, панель свойств, ТЭП и
   выгружаемые документы всегда согласованы; не существует состояния
   «пересчитай/обнови вручную».
2. Клавиатура — первична. Каждое действие достижимо без меню; частые —
   одной клавишей. Раскладконезависимость обязательна (физические коды
   клавиш, не символы).
3. Ничего не пропадает молча. Любая ошибка видна (красный баннер),
   любое фоновое событие объявлено (тост), состояние связи с ядром
   всегда на экране.
4. Пользователь не может испортить данные. Undo покрывает каждый жест;
   автосохранение непрерывно; разрушающих действий без подтверждения нет
   (кроме мгновенно обратимых).
5. Сдержанный светлый интерфейс: внимание — чертежу, хром — на полутонах.

## 2. Структура экрана

```
┌──────────────────────────────────────────────────────────────┐
│ Шапка: логотип · имя проекта · ─── · история · данные · выпуск │
├───┬──────────────────────────────────────────┬───────────────┤
│ T │                                          │  Свойства     │
│ у │                Холст                     │  Подложка     │
│ л │                                          │  Слои         │

│ р │                                          │  ТЭП (живой)  │
├───┴──────────────────────────────────────────┴───────────────┤
│ Статус: координаты · сетка · привязка · ядро · мост · подсказки│
```

- Шапка [есть]: имя проекта — редактируемое поле без рамки (рамка по
  ховеру); кнопки сгруппированы: история (undo/redo), данные (Демо,
  НСПД, Открыть…), выпуск (.grado, DXF, Альбом PDF — главная кнопка
  залита акцентом). [дораб] группировка визуальными разделителями.
- Тулбар [есть]: 44 px, вертикальный, моно-иконки; активный инструмент —
  залитая тёмная плитка; внизу — переключатели-режимы (привязки).
- Правая панель [есть]: 272 px, секции с заголовками капителью,
  скроллится независимо. Порядок секций фиксирован (частые — выше).
- Статус-бар [есть]: слева поток координат/режимов, справа — подсказка
  по горячим клавишам. Индикатор «ядро: ок · vX» обязателен — это
  диагностика фронт/бэк-рассинхрона одним взглядом.

## 3. Холст

- Система координат: метры СК проекта, ось Y вверх; на экране Y вниз
  (правило перевода — только в двух функциях w2s/s2w) [есть].
- Сетка [есть]: точки в узлах мелкого шага (Rayon-стиль), линии каждые
  5 шагов, оси через 0 темнее. Шаг: авто (≥22 px на шаг) или фикс
  1/2/5/10/20/50 м. Текущий шаг всегда в статус-баре.
- Подложка [есть]: тайлы OSM с прозрачностью 10–100%, атрибуция в углу;
  выбор источника (карта OSM/спутник ESRI) на холсте — и в печати/альбоме
  (basemapSource, тот же выбор, что на холсте, сохраняется в проекте).
  [план] офлайн-пакеты тайлов.
- Рендер: перерисовка полного кадра на каждое событие; бюджет кадра
  ≤ 8 мс при 500 объектах [дораб: замерить]. Canvas в flex-контейнере —
  строго flex-basis 0 (иначе цикл самораздувания битмапа).
- Fit (F) [есть]: вписать все объекты с полем 18%.

## 4. Инструменты

| Клавиша | Инструмент | Жест | Результат |
|---|---|---|---|
| V | Выбор | клик / drag вершины / drag тела | выделение, правка |
| G | Граница | клики, замыкание у первой точки | polygon boundary |
| Z | Зона | так же | polygon zone |
| O | Ограничение | так же | polygon restrict |
| B | Здание | drag — прямоугольник; клики — контур | polygon building |
| P | Зона нежилых ОКС | клики | polygon public |
| L | Красная линия | клики, Enter — завершить | polyline redline |
| S | Соцобъект | клик | point social |
| M | Измерение | два клика | эфемерная линейка |

Общие правила рисования [есть]:
- Esc — ступенчатая отмена: набранная длина → текущее рисование →
  измерение → снятие выделения.
- Enter — завершить линию / поставить точку на набранной длине.
- Shift — орто-режим 0/45/90°; длина квантуется по шагу сетки.
- Цифры при рисовании — набор длины (бокс у курсора), Enter — точка
  ровно на этой длине по текущему направлению.
- Возле курсора — живая длина сегмента; у прямоугольника — габариты.
- Замыкание: у первой точки полигона зелёное кольцо-магнит (12 px).

## 5. Привязки

## 8. Слои

Панель в логике QGIS [есть]: чекбокс видимости, образец стиля, имя,

выбирается, исключён из привязок; выделение объекта скрываемого слоя

- [есть] порядок отрисовки перетаскиванием: верхняя строка списка

- [есть] пер-слойное оформление холста (заливка/обводка/толщина/пунктир)

## 15. Критерии приёмки UI (бета)

1. Начертить границу 10 вершин с привязками и орто — без мыши на панели.
2. Нарисовать 3 смежные зоны, получить зелёное «покрытие корректно»,
   подвигать общую вершину — покрытие остаётся корректным.
3. Задать красной линии радиус, пикетаж и построить офсет — 4 действия
   в панели свойств.
4. Скрыть слой участков, начертить поверх, вернуть слой.
5. Получить .grado, открыть его в QGIS, открыть обратно в студии —
   геометрия и свойства идентичны.
6. Выдернуть сервер посреди работы: интерфейс не падает, статус честный,
   после рестарта сервер подхватывается без перезагрузки страницы
   [дораб: сейчас нужен F5].
