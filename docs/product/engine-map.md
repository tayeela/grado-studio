# Карта ядер: что брать вместо своего кода

Живой документ (с 08.10.2026, задача #69). Прежде чем писать свой механизм, агент смотрит сюда: если часть программы
в таблице есть, берётся названное ядро. Новое ядро добавляется строкой в таблицу с решением владельца в
`docs/team/DECISIONS.md`. Обзор скорости — [research-2026-10-08-engines.md](research-2026-10-08-engines.md).

## Решения владельца 08.10.2026 («1А 2Б 3А 4А»)

1. Основа интерфейса — **Vue 3 + dockview + Web Awesome**. Переводим экран за экраном, старое и новое живут рядом,
   пока экран не переведён целиком.
2. **Сборка через Vite.** Собранные файлы лежат в репозитории, поэтому на Mac, на сервере и в установщике Node не нужен;
   CI проверяет, что собранное совпадает с исходниками.
3. Редактор листов — **свой, на Konva**, с нашей моделью листа (рамка, штамп, карта, легенда, таблица). PPTist отклонён:
   лицензия AGPL.
4. Порядок: **сначала каркас интерфейса** (окна и панели), затем на нём редактор листов.

Не меняются: схема координат МСК/ОГД (железное правило 3), инсоляция, нормы, правила подписей и оформления альбома —
это предметная логика. Команды в духе AutoCAD (обрезать, удлинить, командная строка) остаются нашими: готового ядра нет,
но геометрию под ними берём готовую.

## Карта по частям программы

| Часть программы | Сейчас | Ядро | Запасной вариант | Что даёт |
|---|---|---|---|---|
| Каркас интерфейса | обычный JavaScript, общие переменные, порядок файлов важен | **Vue 3** (MIT), подключается постепенно, экран за экраном | Lit (BSD) без каркаса | порядок в коде, экраны не ломают друг друга |
| Окна и панели (21 окно) | свои стыковка, перетаскивание, вкладки, около 300 строк | **dockview** (MIT) | Lumino (основа JupyterLab) | надёжная стыковка, сохранение раскладки; правило «не больше двух окон в зоне» сохраняем |
| Кнопки, меню, формы, диалоги | четыре разных меню, свои диалоги, `prompt()` | **Web Awesome** (MIT, преемник Shoelace) | Spectrum (Adobe) | единый вид всех элементов, клавиатура и диктор работают сами |
| Таблица атрибутов | своя HTML-таблица, две копии | **Tabulator** (MIT) | AG Grid Community | сортировка, фильтр, быстрая работа на тысячах строк |
| Дерево слоёв | своё дерево, второе в «Исходных данных» | компонент Vue + **SortableJS** (MIT) | — | одно дерево вместо двух |
| Рисование и правка на карте | свои привязки трёх видов | **OpenLayers** Draw/Modify/Snap (уже есть) + **ol-ext** направляющие | terra-draw | меньше своего кода; командная строка AutoCAD остаётся нашей |
| Геометрия на сервере | своё наложение (приближённое), повторы в 4 файлах | **shapely 2** (BSD), задача #71 | — | точные площади и вычитание; ТЭП может слегка измениться, сверяем |
| Схема расчёта (граф узлов) | litegraph 0.7.18, заморожен с 2024 | **Rete.js 2** (MIT) | Vue Flow | живая библиотека вместо брошенной; нужен перенос сохранённых схем |
| Отмена и повтор | три отдельных механизма, в листах отмены нет | один общий механизм (при совместной работе — из Yjs) | Immer | Ctrl+Z работает везде одинаково |
| Совместная работа | своё слияние правок | **Yjs** (MIT) + pycrdt на сервере | оставить своё | проверенное слияние без потерь; большой шаг, не первым |
| Редактор листов | свой, на HTML и SVG | свой редактор на **Konva** (MIT) с нашей моделью листа | Fabric.js (MIT) | выделение, ручки, направляющие, слои листа из коробки |
| Карта на листе | своя | OpenLayers с точным масштабом (пример «печать в масштабе») | — | масштаб как в QGIS |
| PDF альбома | свой писатель PDF, шрифт вшивается целиком | **ReportLab** (BSD) | оставить свой | файлы меньше, текст ищется, меньше поломок |
| PPTX | свой из кусков XML | **python-pptx** (MIT) | — | меньше ошибок в PowerPoint |
| Любой шрифт в печати | только три своих TTF | **fontTools** (MIT): чтение шрифтов компьютера, OTF (CFF) и TTC → TTF для печати | — | любой шрифт с русскими буквами в PDF и PPTX (владелец 10.10.2026) |
| Сервер (2 600 строк) | ручной разбор адресов, проверки повторены | **Starlette** (BSD) + **pydantic** для формата проекта | оставить | проверка данных на входе, порядок в адресах |
| Запросы к порталам | пять своих циклов повтора, свой кэш | **httpx** + **tenacity** (≤ 3 повтора, паузы) | — | одно правило повторов на все порталы |
| Тесты | свой браузерный драйвер под Mac | **pytest** + **Playwright** | — | тесты одинаково идут на Mac, Windows и в облаке |

Образец 11.10.2026 (Даниил: «deckcraft возьми как основу для редакторов листов»): **deckcraft**
(github.com/storytold/deckcraft, MIT OR Apache-2.0, автор — Storytold / ArtCraft) — редактор презентаций на Rust со своим
интерфейсом (egui) и форматом PowerPoint. Целиком в окно ГРАДО не встаёт (другой язык, свой холст и свои панели, карта
и ГОСТ-штамп в нём не рисуются), поэтому взято его устройство: каждая кнопка ленты — команда с отменой и подписью, её же
набирают в командной строке (`apps/grado2/ui/src/sheet/commands.js`); группы, отражение, «Формат по образцу», точный сдвиг,
поворот и размер (`apps/grado2/ui/src/sheet/arrange.js`). Перенесённые места помечены в заголовках этих файлов; лицензия MIT
разрешает перенос с указанием источника.

Отклонено 08.10.2026: PPTist — лицензия AGPL (придётся открыть код ГРАДО или покупать лицензию у автора); Polotno — платный,
код закрыт; tldraw — нужен платный ключ; QGIS как движок печати — GPL и тяжёлый; React — тяжелее для постепенного
перехода; golden-layout и WinBox — заброшены; Shoelace — закрыт в мае 2026, его заменил Web Awesome.
