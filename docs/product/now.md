# Что дальше

Короткая страница: где программа сейчас и что делать дальше. Свежее состояние — верх
[../grado2-changelog.md](../grado2-changelog.md) и открытые задачи GitHub (`gh issue list`);
эта страница — снимок на 07.11.2026 и сама не обновляется.

## Где программа сейчас (07.11.2026, v0.99.122)

- Цель «от границы до пакета материалов за один рабочий день» — цель, а не факт
  ([README](../../README.md)); план и критерии приёмки — [plan.md](plan.md).
- Адрес сайта открывает новый интерфейс (v0.99.70); сценарии приёмки C–N в нём гоняются
  автоматически, без интернета (v0.99.82). Прежний интерфейс остаётся рядом.
- Сайт <https://grado.tailink.tech>: вход на странице сайта через Telegram (v0.99.108–109);
  совместный режим — роли, команды, доступ по ссылке ([../guides/collab.md](../guides/collab.md)).
- Замечания владельца по альбому Безобразово правятся в самой программе (#144, v0.99.107);
  знаки ЛГР выбираются в «Свойствах» (v0.99.114).
- Тесты в CI идут на каждый пуш в main, зависимости замкнуты `requirements.lock`, сохранение
  проекта переживает выключение питания (v0.99.116, v0.99.121).

## Что делать дальше

1. **Запустить программу.** На экране — файл «ГРАДО 2.command» (Mac) или «ГРАДО 2.bat» (Windows)
   в корне репозитория → двойной клик; первый запуск сам ставит окружение → браузер открывается
   на `http://localhost:8650`, видно рабочее место с картой. Подробно —
   [../guides/install.md](../guides/install.md).
2. **Работать вдвоём.** На экране — страница <https://grado.tailink.tech> → кнопка
   «Войти через Telegram» (логин и пароль — под ссылкой) → список проектов. Роли, команды
   и доступ по ссылке — [../guides/collab.md](../guides/collab.md).
3. **Проверить приёмку.** На экране — терминал в корне репозитория (Mac владельца) →
   набрать `node tools/acceptance_run.mjs`; без аргументов берётся граница «Пример», поднимается
   отдельный сервер на порту 8652 с временной папкой проектов, рабочие данные не трогаются →
   в папке «ГРАДО приёмка» на рабочем столе появляется отчёт `report.md`: время каждого шага,
   слои выгрузки, ошибки консоли. Описание — [../ux/acceptance.md](../ux/acceptance.md).
4. **Править код.** Перед коммитом — в терминале `python3 tools/gate.sh` → должно напечатать
   «GATE: OK» (число скипов видно в итоге); правки интерфейса без node_modules дают FAIL,
   а не тихий пропуск (v0.99.121).
5. **Вести очередь.** Свежие задачи — `gh issue list`; срез состояния — «Where we are»
   в [plan.md](plan.md), причины решений — [../team/DECISIONS.md](../team/DECISIONS.md).
   Из v0.99.121 не сделано: владельцу — поставить branch protection на main в настройках
   GitHub (merge только зелёным PR); команде — подключить mypy для `core/`, включить ruff-стиль
   поэтапно.
