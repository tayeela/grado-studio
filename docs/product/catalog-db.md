# Каталог проектов, база данных и совместная работа

Решение 12.10.2026 по просьбе Даниила («название проекта нельзя редактировать, каталог неудобен; придумай СУБД и совместную работу,
с превью, на готовых решениях»). Владелец выбор не делает — выбрано здесь, с причинами.

## Что сделано (v0.99.95)

- **Название в шапке правится щелчком**: Enter — записать, Esc — отмена. Сохранённый проект переименовывается в папке вместе
  с прежними версиями (`.versions/`); несохранённая работа сохраняется под этим названием.
- **Окно «Проекты» (Ctrl+O)** — карточки с превью территории: поиск, «Все / Избранные / С альбомом», порядок
  (изменённые, открытые, по названию), звёздочка, меню карточки (открыть, переименовать, копия, скачать, в корзину),
  карточка «Новый проект», «Файл с диска…», «Корзина» с кнопкой «Вернуть».
- **«Совместные проекты»** на общем сервере — те же карточки и превью (одна логика на всю программу).

## Референсы аналогов

Карточки с превью, звёздочка, недавние, корзина с возвратом — как стартовые окна Figma, Autodesk Forma и «Недавние проекты» QGIS
(превью карты у каждого проекта) и корзина Google Drive. Действия карточки в одном меню «…», как в Figma; переименование
на месте по двойному щелчку — как в Finder.

## База: SQLite (входит в Python, ничего ставить не надо)

| что | где | почему так |
|---|---|---|
| сами проекты | файлы `.grado2` в папке проектов, как раньше | видно в Finder, копирует Time Machine, файл можно переслать |
| каталог: превью, избранное, «открывали» | `.catalog.sqlite` в той же папке (`apps/grado2/catalog.py`) | одна база-файл, транзакции, работает на Mac и Windows без установки |
| корзина | папка `.trash` в папке проектов | удаление обратимо; совсем удалить — убрать файл оттуда в Finder |
| превью общих проектов | `catalog.sqlite` в папке хаба | пересчёт по ревизии проекта |

База — только память каталога: если её удалить или она испортится, проекты целы, база соберётся заново (испорченная
откладывается рядом с пометкой `broken`). Превью рисует сервер из слоёв проекта (Pillow), без подложки и без интернета:
видимые слои своими цветами, граница территории — синей линией; пересчёт — когда файл изменился.

Отклонено: PostgreSQL/PostGIS — нужен отдельный сервер, на ноутбуке градостроителя лишний; GeoPackage как формат проекта —
хорош для слоёв QGIS, но в проекте ещё листы, альбом, схема расчёта; перевод формата — отдельная большая работа.

## Совместная работа: что уже есть и что дальше

Уже работает общий сервер (`apps/grado2/hub.py`, контракт — [../specs/collab-contract.md](../specs/collab-contract.md)): учётные записи,
роли (владелец, правка, просмотр), команды, ссылка-приглашение, правки разделами с ревизиями, кто сейчас в проекте,
комментарии на карте, история версий.

Следующий шаг (не сделан, предложение): перевести служебные файлы хаба (`users.json`, `sessions.json`, `meta.json` проектов)
в ту же SQLite в режиме WAL — один файл, атомарные записи без самодельных замков; тела проектов остаются файлами.
Одновременная правка одного раздела двумя людьми — на готовом движке CRDT (Yjs) вместо слияния по ревизиям, когда это станет нужно.
