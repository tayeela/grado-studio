# Аудит функций опубликованной Студии и где они в релизе

Сверено с локальной бетой `0.9.0-beta.106` (`apps/studio/web/index.html`, коммит `7ca4559`) и с `origin/main` (`beta.89`). Набор команд релиза — более полный beta.106: на GitHub ветка `main` отстаёт, но те же семейства действий уже были там.

Релиз открывается по `/`. Прежняя бета остаётся по адресу `/index.html`.

Визуальные ориентиры, не копии:

- AutoCAD: командная строка, орто, привязка, строка состояния со СК и масштабом.
- Rayon (rayon.design): светлый чертёжный лист, узкая рейка инструментов, инспектор справа, без леса кнопок на всю ширину.

| Функция беты | Релиз |
|---|---|
| Выбор и правка вершины | рейка «Выбор», перетаскивание вершины через `/api/geom` `vertex` |
| Точка, линия, полигон, прямоугольник | команды и рейка, прямоугольник — `rectangle` |
| Дуга по 3 точкам, окружность | `arc3`, `circle`, колонка `curve` в `.grado`; холст рисует дугу и круг из параметров, без сохранённой полилинии |
| Обрезать, продлить, склеить | `trim`, `extend`, `join` |
| Сопряжение, буфер | `fillet`, `buffer` |
| Поворот, масштаб, зеркало | `rotate`, `scale`, `mirror` |
| Размер, измерение | `dim` (в DXF, не в ТЭП), `measure` |
| Привязки, орто, сетка | `snap`, орто на холсте, `grid` |
| Панорама, масштаб, вписать | колесо, Alt-перетаскивание, «Вписать» |
| Отмена и возврат | кнопки и ⌘Z |
| Слои: видимость и захват | полки участка и импорта НСПД, OSM, ГИС ОГД, ФГИС ТП; два флажка |
| Знаки ЛГР | команда `знак <style_id>`: обводка, штрих, штриховка и точки из библиотеки, тот же набор в `projectStyles` |
| Подложка OSM / снимок | `/api/tiles`, переключатель OSM / Снимок / без |
| НСПД | «Забрать захват» через `/api/inbox` и `/api/import-nspd` |
| OSM и НСПД по области | карточки источников, состояния нет / грузится / снимок и дата |
| ГИС ОГД ZIP | кнопка и `/api/import-gisogd` |
| ФГИС ТП, каталог и УИН | поле: название ищет каталог, цифры УИН грузят документ |
| Живой ТЭП | `/api/tep`, без границы «н/д», пустая этажность не становится 9 |
| Предпроверка, PDF, альбом, DXF, `.grado` | вид Альбом и «Сохранить» |
| Командная палитра | «Команды» и ⌘K |
| data.mos.ru | не предлагается |

Каталог ФГИС ТП целиком в рейку не выгружается: документ берётся по УИН, как рабочий путь импорта беты. Покрытие школ и ДОО по-прежнему не считается.
