# Установка ГРАДО Студии на компьютер

Студия работает локально в браузере: небольшой сервер запускается на вашем
компьютере, а сама студия открывается в обычном браузере по адресу
`http://localhost:8643`. **Данные никуда не уходят** — сервер слушает только
этот компьютер, интернет нужен лишь для карты-подложки и загрузки данных
(OSM, НСПД). Работает на **macOS** и **Windows** (нужен Python 3.8+).

## Браузерная редакция без установки

Откройте <https://tayeela.github.io/grado-studio-pages/>. Проект хранится в
браузере; резервную копию можно скачать через **«Проект → Скачать проект
браузера»** и затем открыть на этом же сайте. Черчение, слои, привязки, демо,
варианты и предварительный ТЭП работают без установки. PDF, DXF, альбомы,
буферы и серверный импорт НСПД/ГИС ОГД требуют настольную версию ниже.

Полноценную браузерную Студию с PDF, DXF, альбомами и совместной работой можно
развернуть на сервере в Docker. Инструкция: [CLOUD_DEPLOY.md](CLOUD_DEPLOY.md).

# Windows

## Готовое приложение (рекомендуется)

1. Скачайте `GRADO-Studio-Setup-….exe` со страницы
   [выпусков](https://github.com/tayeela/grado-studio-pages/releases/latest).
2. Запустите установщик. Python, библиотеки и исходники устанавливать не нужно.
3. Откройте **«ГРАДО Студия»** из меню «Пуск». Файлы `.grado` после установки
   открываются двойным кликом.

Установщик ставится только для текущего пользователя и не требует прав
администратора. Пока выпуск не подписан коммерческим сертификатом, Windows
SmartScreen может показать «Неизвестный издатель»: откройте «Подробнее» →
«Выполнить в любом случае», если файл скачан по ссылке выше.

В том же выпуске есть `…-windows-portable.zip`: его можно распаковать в любую
папку и запускать `ГРАДО Студия.exe` без установки.

Автосохранения, проекты хаба, кэш и настройки находятся в
`%LOCALAPPDATA%\GRADO Studio`. Обновление или удаление программы их не стирает.

## Запуск из исходников

1. Установите **Python 3** с <https://www.python.org/downloads/>.
   **Важно:** при установке поставьте галочку **«Add Python to PATH»**.
2. Дважды кликните файл **`ГРАДО Студия.bat`** в папке проекта.
   - Откроется чёрное окно с сообщениями, при первом запуске доустановится
     небольшой компонент `certifi` (для карты-подложки).
   - Затем откроется браузер со студией. **Пока окно открыто — студия
     работает.** Чтобы завершить — закройте это окно.
3. Открыть готовый проект `.grado` можно, перетащив файл на `ГРАДО Студия.bat`.

Этот способ нужен только разработчикам или если используется полный архив
исходников. Повторный запуск просто откроет уже работающую Студию. Если передан
другой файл `.grado`, он откроется на свободном локальном порту и не потеряется.
Автосохранения, кэш и настройки находятся в
`%LOCALAPPDATA%\GRADO Studio`, поэтому папку программы можно обновлять или
перемещать без потери рабочих данных.

Если в чёрном окне текст выглядит «кракозябрами» — это косметика (кодировка
консоли), на работу не влияет.

## Карта-подложка и печать (Windows)

- Печать и альбом (PDF) используют системные шрифты Windows (Arial/Tahoma) —
  работают из коробки.
- Карта OSM в PDF использует пакет **Pillow** (для конвертации картинок).
  Лаунчер устанавливает его автоматически при первом запуске. Если установка
  не удалась, выполните `py -m pip install --user Pillow`; без Pillow можно
  использовать **спутник** — он работает без конвертации.
- Импорт ГИС ОГД из shape-файлов требует **QGIS** (для `ogr2ogr`); студия сама
  найдёт его в `C:\Program Files\QGIS…`. GeoJSON-выгрузки ГИС ОГД импортируются
  без QGIS.

# macOS

## Готовое приложение из DMG (рекомендуется)

1. Скачайте `GRADO-Studio-…-macOS-universal.dmg` со страницы выпусков.
2. Откройте DMG и перетащите **«ГРАДО Студия»** в **«Программы»**.
3. Запустите приложение из папки «Программы». Python и исходники не нужны.

Сборка universal2 работает на Apple Silicon и Intel Mac. Пока выпуск подписан
только локальной подписью, при первом запуске на другом компьютере macOS может
заблокировать приложение. Откройте **Системные настройки → Конфиденциальность
и безопасность** и нажмите **«Всё равно открыть»**. После подключения
Developer ID и notarization это предупреждение исчезнет.

Файлы `.grado` открываются двойным кликом или перетаскиванием на иконку
приложения.

## Способ 2 — двойной клик по исходникам

1. Убедитесь, что установлен **Python 3** (проверить: откройте «Терминал» и
   введите `python3 --version`). Если его нет — скачайте с
   <https://www.python.org/downloads/> и установите.
2. Дважды кликните файл **`ГРАДО Студия.command`** в папке проекта.
   - Первый раз macOS может спросить разрешение: нажмите правой кнопкой →
     «Открыть» → «Открыть».
   - При первом запуске автоматически доустановится небольшой компонент
     `certifi` (для карты-подложки) — это занимает пару секунд.
3. Откроется окно Терминала с сообщениями и браузер со студией. **Пока окно
   Терминала открыто — студия работает.** Чтобы завершить — закройте это окно.

Открыть готовый проект `.grado` можно, перетащив файл на иконку
`ГРАДО Студия.command` (или «Открыть с помощью»).

## Способ 3 — самостоятельная сборка DMG

Собирает автономное приложение с фирменной иконкой в Dock и ассоциацией
файлов `.grado`. Требует установленного `py2app`:

```sh
python3 -m pip install --user py2app
python3 packaging/build_macos.py
```

Готовые `.app` и universal2-DMG появятся в `dist/`. Сборщик исправляет
совместимость открытия файлов с актуальной macOS, проверяет обе архитектуры и
целостность подписи, создаёт DMG с ярлыком «Программы».

При повторном запуске приложение не создаёт второй конфликтующий сервер, а
открывает уже работающую Студию. Если двойным кликом открыть отдельный файл
`.grado`, пока Студия работает, файл будет открыт на другом свободном локальном
порту и не потеряется.

Сборка включает только системные ресурсы: локальные автосохранения, кэши,
пользовательские стили и служебные файлы в `.app` не попадают. Если менялся
SVG-исходник иконки, перед сборкой пересоздайте `.icns`:

```sh
packaging/build_icon.sh
```

По умолчанию сборка подписывается временной подписью. Для Developer ID и
notarization задайте `MACOS_SIGN_IDENTITY` и сохранённый профиль
`MACOS_NOTARY_PROFILE`; сборщик подпишет приложение, отправит DMG в Apple и
прикрепит notarization ticket.

## Способ 4 — вручную из Терминала (для отладки)

```sh
cd путь/к/grado-studio
python3 apps/studio/server.py 8643 --open
```

## Если что-то не так

- **«Не найден Python 3»** — установите Python с python.org и запустите снова.
- **«Порт 8643 занят»** — студия уже запущена в другом окне (просто откройте
  `http://localhost:8643`) либо порт занят другой программой — закройте её.
- **Не грузится карта-подложка** — не установился `certifi`. Выполните в
  Терминале: `python3 -m pip install --user certifi` и перезапустите.
- **Не импортируется ГИС ОГД из shape-файлов** — нужен `ogr2ogr` (входит в
  QGIS-LTR). GeoJSON-выгрузки ГИС ОГД импортируются без него.

Данные проекта хранятся в браузере и дублируются на диск — переживают
перезагрузку. При запуске из исходников резерв находится в
`apps/studio/.autosave.json`; Windows-лаунчер хранит их в
`%LOCALAPPDATA%\GRADO Studio`, а приложение `.app` — в
`~/Library/Application Support/ГРАДО Студия/`, поэтому замена приложения не
стирает проекты и настройки. Полноценно сохранить проект можно через меню
**«Проект → Сохранить проект (.grado)»** или `⌘S` (файл открывается и в QGIS).

Перед сохранением, DXF, печатью и сборкой альбома Студия проверяет проект.
Блокирующие ошибки нужно исправить; предупреждение можно принять и продолжить
выпуск.

# Веб-режим: совместная работа (несколько человек)

Тот же сервер умеет работать как веб-хаб с входом по логину/паролю и
совместным редактированием проектов в реальном времени. Включается флагом
`--hub`:

```sh
python3 apps/studio/server.py 8643 --hub
```

При первом запуске в консоль печатается **стартовый инвайт-код** — по нему
регистрируется первый пользователь (он становится администратором). Дальше:

- **Вход/регистрация** — по инвайт-коду. Администратор выдаёт коды коллегам
  кнопкой «+ инвайт» в окне «Проекты».
- **Проекты** живут на сервере (папка `apps/studio/.hub/`), у каждого свой
  список; владелец делится проектом кнопкой «Поделиться» (по логину коллеги).
- **Живая синхронизация** — правки каждого появляются у остальных через ~2-3
  секунды. Если двое одновременно правят один объект — сохраняется версия
  того, кто записал последним, с уведомлением; добавления/удаления разных
  объектов объединяются автоматически. Личное (масштаб, активный слой,
  отмена/повтор) у каждого своё.

**Важно для публичного размещения (на сервере с доменом):**

- **Обязателен HTTPS**: без него пароль передаётся по сети открытым текстом.
  Облачный режим помечает session-cookie как Secure и включает защитные
  заголовки, но TLS должен завершать reverse-proxy или облачная платформа.
- Не размещайте веб-хаб на сервере, где крутится другая чувствительная
  инфраструктура — лучше отдельная машина.
- Локальный режим (без `--hub`) авторизацию не использует — он для работы на
  своём компьютере и слушает только `localhost`.
