## 2. Население (п. 1.4.2–1.4.4, табл. 1.4.1)

### Правило П1. Расчётное население новой застройки
**П. 1.4.2:** расчётное население определяется площадью квартир на одного человека.

**Таблица 1.4.1 «Показатели расчета населения по типам жилой застройки»**

| № | Тип жилого дома (код ВРИ по приказу Росреестра П/0412) | Площадь квартир на 1 чел. |
|---|---|---|
| 1 | Многоквартирный дом (2.1.1, 2.5, 2.6) | 33 кв.м на человека |
| 2 | Индивидуальный жилой дом (2.1) | 50 кв.м на человека |
| 3 | Жилой дом блокированной застройки (2.3) | 50 кв.м на человека |

Формула:

```
N_расч = Σ по типам ( S_кв,тип / норма_тип )
  норма_МКД = 33 м²/чел;  норма_ИЖД = 50 м²/чел;  норма_блок = 50 м²/чел
  S_кв — «площадь квартир» по п. 1.2.1.20 (без лоджий, балконов и т.п.)
```

### Правило П2. Существующее население
**П. 1.4.3:** по актуальным данным Мосгорстата (расчётом не определяется).

### Правило П3. Прогнозируемое население
**П. 1.4.4:** `N_прогн = N_сущ + N_расч` (в границах проектирования).

Формула (для каждой строки):

```
S_ННП,треб,i = N / 1000 × норма_i        [м² ННП]
Итого повседневный спрос = 270 + 100 + 120 = 490 м² ННП / 1000 жит.   (сумма строк 1.1–1.3)
Итого периодический спрос = 150 + 90 = 240 м² ННП / 1000 жит.         (сумма строк 2.1–2.2)
Всего по табл. 1.3.1 = 730 м² ННП / 1000 жит.
```
(Суммы — арифметика по строкам таблицы; сама таблица итогов не даёт.)

Проверка доступности: каждый жилой дом должен лежать в пределах радиуса (или времени) от границы участка хотя бы одного объекта своей категории.

## 10. Неоднозначности

- **Н1.** Сноски табл. 1.4.2 не привязаны к строкам ни в md, ни в html. Привязка в разделе 5.1 — толкование (по упоминанию «территории реконструкции» и по коэффициенту 0,6). Неясно, распространяются ли минимальные размеры площадок 100/50 м² и правило совмещения < 15 м² на МГК (строки 3.1.1–3.1.2).
- **Н2.** Какое население брать в нормах «на 1000 жителей» и «кв.м/человека»: расчётное (новое) или прогнозируемое (существующее + расчётное, п. 1.4.4). Прямо не сказано. Для территорий реконструкции логично прогнозируемое, для преобразования (нежилая территория) они совпадают.
- **Н3.** Округление численности населения не регламентировано.
- **Н4.** Табл. 1.4.1 задана через «площадь квартир», а в ТЭП ППТ обычно известна наземная площадь (СПП) или «жилая наземная площадь» (п. 1.2.1.7(1)). Коэффициента перехода от наземной площади к площади квартир в документе нет — его нужно задавать отдельно. «Общая площадь квартир» может превышать «площадь квартир» до 10 % (п. 1.2.1.21), но в расчёт населения идёт именно «площадь квартир».
- **Н5.** Библиотеки (табл. 1.3.3, стр. 13): даны оба показателя — «1 на 3000 единиц хранения» и «27 кв.м» ННП на место; как их сочетать, не сказано.
- **Н6.** «Или 20 минут / 30 минут» — время по транспортно-пешеходному маршруту с учётом скорости общественного транспорта и подхода к остановке (п. 1.2.1.2); скорость не задана.
- **Н7.** Реконструкция, строка 1.1: 25 % «территории квартала (микрорайона)» — если граница проектирования не совпадает с кварталом, неясно, к какой площади применять.
- **Н8.** Для строки 2.2 и 3.2 (ОТОП) из п. 1.4.5.1.2 исключаются озеленённые полосы УДС; для строки 1.1 (реконструкция, «ЖК и ОТОП» вместе) это исключение формально тоже действует (п. 1.4.5.1.2 общий).
- **Н9.** Снижение на 15 % при ОТОП ≥ 5,0 га: не сказано, суммируется ли оно с компенсационными снижениями Садового кольца.
- **Н10.** Размер денежной компенсации в документе не установлен (правовой акт ДГП).
- **Н11.** «Зона сохранения квартала» определена (п. 1.2.1.11), но собственных показателей в табл. 1.4.2 не имеет.
