# Стандарты: правила, образцы, шрифты, нормы

Здесь лежит то, что программа читает при работе и чем проверяют результат. **Папка уходит на сервер вместе с программой**
(`tools/server_pull/grado-pull.sh` берёт `apps/grado2`, `core`, `docs/standards`), поэтому всё, что лежит здесь, должно быть нужно программе
или правилам; прочие документы кладите на другие полки ([../INDEX.md](../INDEX.md)).

| папка или файл | что это | кто использует |
|---|---|---|
| [albums/label-rules.md](albums/label-rules.md) | графические правила подписей и оформления листов альбома по замечаниям владельца; **главнее остальных** | печать (`print_io.py`, `album_io.py`), агенты; свод — [../wiki/album-rules.md](../wiki/album-rules.md) |
| [albums/slide-layout-rules.md](albums/slide-layout-rules.md) | общие правила вёрстки слайдов А3: формат, сетка, типографика, карта, легенда, таблицы, фотографии, проверка перед выпуском | вёрстка и проверка листов |
| [albums/layout-qa.md](albums/layout-qa.md) | контрольный список оформления листа: что проверить глазами и компьютером до слова «готово» | навык `album-verify`, аудит (`docs/team/prompts/album-design-audit.md`), `tools/album_lint.py` |
| `albums/pptkrt-header.jpg`, `albums/*.dxf`, `albums/icons/` | образцы владельца: красная шапка ППТ КРТ, ВРИ земельных участков, условные обозначения Генплана, значки станций | легенда, шапка листа, подписи станций |
| `admin/moscow-adm.geojson` | эталон округов и районов Москвы (132 района) | слой `gisogd.admin` |
| `fonts/` | Montserrat, PT Sans, PT Serif и их лицензии | печать PDF и PPTX |
| `redln97/` | типы линий `REDLN97.LIN` и `RED_LNS.SHX` для AutoCAD | экспорт DXF, стили ЛГР |
| [moscow-ngp/](moscow-ngp/README.md) | нормативы Москвы: тексты постановлений (945-ПП, 1557-ПП, 2150–2152-ПП) и выписки алгоритмов расчёта ТЭП | движок ТЭП, нормоконтроль |
| [regulations-moscow.md](regulations-moscow.md) | профиль норм Москвы: что программа проверяет сама, а что требует отдельных данных | нормоконтроль |

Стили ЛГР (`core/render/grado_render/styles/*.json`) **генерируются** скриптами `tools/gen_*.py`, руками их не правят.
