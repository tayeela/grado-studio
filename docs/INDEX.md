# Документы ГРАДО 2 — карта полок

Одна страница, с которой начинается любой поиск по `docs/`. Документы лежат по смыслу, а не по дате: живое — на полках,
история — в `archive/`. Правила работы с документами — [CLAUDE.md](CLAUDE.md); соответствие карты и папок проверяет
`tools/docs_check.py` (в `tools/gate.sh` и в CI): битая ссылка, документ «ни на какой полке» или файл кода без заголовка
сразу видны.

## Сквозные правила (подробно — в CLAUDE.md и в вики)

- Источник правды — GitHub: задачи и слова владельца в Issues, работа в PR в `team/t60`, выкладка PR `team/t60 → main` по слову «выкладывай».
- Новое замечание владельца по альбому — сначала правило (`standards/albums/label-rules.md`, `wiki/album-rules.md`), потом код.
- Журналы (`grado2-changelog.md`, `team/PROGRESS.md`, `team/DECISIONS.md`) только дописываются сверху и в архив не уходят.
