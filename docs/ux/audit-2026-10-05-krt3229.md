## Process findings (owner path)
- Blocker: no way to set the territory from a KRT number or by clicking a KRT object («Сделать границей» exists only
  for cadastral search results) — the lead used the browser console.
- Blocker: «Штамп…» has no fields for KRT number (`short`), «округ, район» (`place`), address; `place` comes from the
  ТЭП node via Overpass and is empty without a warning when Overpass fails.
- Important: first assembly 4–5 min with no progress (T62 on team/t60 adds it, not landed).
- Important: no pre-export checklist (territory, district, empty layers, photos, «не готов» sheets).
- Minor: PDF/PPTX wait 17–28 s without a hint.

## Code findings (architect)
- okrugMain can drop the part that holds the territory (KRT in пос. Восточный) — keep the part with the centroid.
- All sheets on yandex.hd_roads: no fallback where Yandex has no polygons (ТиНАО, not verified); roadShare and the
  legend item depend on it — fallback to egko.roads / axes, legend item only when roads are visible.
- Yandex tiles: 404 counted as failure → 5 edge 404s switch Yandex off for 10 min (mixed imagery); Esri drawn under
  the whole sheet on any miss; >600 tiles → no basemap silently; frozen Безобразово sheets switch to Yandex too.
- Spec 10+ MB (unrounded geometry); corner districts taken from the degree bbox, not the МСК frame; formula of the
  ortho legend height duplicated; PPTX group order of `over` layers vs photo marks.
- Tests missing: yandex_sat_tile fallback, mapNoteBR, `over` order, okrugMain, conceptRail/conceptDistricts.
- Merge: team/t60 merges with conflicts only in version/changelog; team2 (uncommitted T69–T71) conflicts in
  admPanelSpec (simplifyAdm vs okrugMain) and wraps self.tiles (loses `.ysat`) — merge main into team2 first.
