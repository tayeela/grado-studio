# Приёмка ГРАДО 2: Хорошёво и участок в Новой Москве

Цель продукта ([../product/plan.md](../product/plan.md)): от границы территории до пакета материалов за рабочий день, на двух
эталонных территориях — Хорошёво (46 га, плотная старая Москва) и участок в Новой Москве (Троицкий или Новомосковский округ, новая застройка), без ошибок в консоли. Здесь — что проверяется само, а что делает владелец.

## Проверяется само (GitHub, без порталов)

| что | где | как запустить |
|---|---|---|
| сценарии C, D, E, G, H, N в новом интерфейсе: эскиз и ТЭП, варианты и «Объём», выгрузки DXF, GeoJSON, Excel, раскладка окон, радиусы обслуживания, виды | `apps/grado2/tests/e2e/next_acceptance.mjs` | каждый PR (задача `test`) или `E2E=1 tools/gate.sh` |

## Прогон на настоящей территории (Mac владельца, с порталами)

Скрипт `tools/acceptance_run.mjs` сам открывает новый интерфейс в Chrome и проходит путь градостроителя, засекая время:
граница → выгрузка трёх наборов («Существующее положение», «Ограничения», «Градостроительная документация») →
«Рассчитать ограничения» → эскиз под цель плотности → «Подобрать варианты» → альбом ППТ КРТ в PDF → DXF, GeoJSON, Excel.

- Работает на отдельном сервере (порт 8652) и во временной папке проектов: рабочая программа на 8650 и «Документы/ГРАДО 2» не
  трогаются; из проекта владельца берётся только граница.
- Кэш по умолчанию пустой — это и есть «замер с пустым кэшем». Ваш `~/.grado2/cache` не удаляется: скрипт даёт серверу
  временную домашнюю папку и копирует туда только сертификаты НСПД. С `--warm` — обычный кэш.
- Итог — папка на рабочем столе «ГРАДО приёмка/<имя> <дата>»: `report.md` (шаги, время, какие слои пришли, ошибки консоли),
  снимки экрана после каждого шага, `альбом.pdf`, архивы DXF и GeoJSON, `тэп.xlsx`.

Хорошёво — граница «Пример» (46,09 га), файл не нужен:

```
cd ~/grado-studio && git pull && (cd tools && npm ci) && node tools/acceptance_run.mjs --name Хорошёво
```

Новая Москва — учебный участок в Троицком округе, поселение Краснопахорское, у Калужского шоссе севернее Красной Пахры
(51 га, `tools/acceptance/troitsky-krasnopahorskoe.geojson`), или граница из вашего проекта (берётся только граница):

```
cd ~/grado-studio && node tools/acceptance_run.mjs --name Краснопахорское --boundary tools/acceptance/troitsky-krasnopahorskoe.geojson
cd ~/grado-studio && node tools/acceptance_run.mjs --name <имя> --project "$HOME/Documents/ГРАДО 2/<проект>.grado2"
```

Флаг `--headed` показывает окно Chrome во время прогона.
