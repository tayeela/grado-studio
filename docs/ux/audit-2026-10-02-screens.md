## Не проверено
- Реальные Retina-экраны (devicePixelRatio 2) и системное масштабирование Windows 125/150%: снимки сделаны при 1x.
- Тёмная тема, перетаскивание окон между панелями на 840 px (touch), режим hub, печать.
- Загрузка ГИС ОГД и данных порталов: брал только «Пример» (локальный прямоугольник); карта-подложка OSM грузилась из сети, на 840 в одном кадре тайлы не успели.
