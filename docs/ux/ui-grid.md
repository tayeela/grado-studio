# Новый интерфейс: сетка окон и полей

Правила, по которым собраны окна нового интерфейса (`apps/grado2/ui`) после замечания владельца 09.10.2026
(«элементы не по уровню, скачут, не влезают в окошки, везде ползунки ненужные, перемещение окон работает криво»).
Числа живут в коде — [theme.css](../../apps/grado2/ui/src/theme.css); здесь — что и почему. Новое окно делается по этим правилам.

## Строка свойства

- Подпись слева, поле справа: класс `.f` (`<label class="f"><span>Подпись</span><поле/></label>`), несколько полей в строке — внутри `.fc`.
  Колонка подписи одной ширины во всём окне, все поля одной высоты (`--wa-form-control-height`), между строками 6 px.
  Так устроены инспекторы Figma, Blender и Apple (панель свойств выбранного объекта).
- Единица измерения и процент — после поля, мелко и серым (`.u`; значение ползунка — `.u.v`, колонка одной ширины, цифры одной ширины).
- Числовое поле — `.num` (фиксированная ширина), кнопки «−» и «+» узкие, число посередине видно всегда.
- Подпись над полем — только в диалогах (сохранить проект, новый слой): там поле во всю ширину.

## Разделы и кнопки

- Заголовок раздела один во всех окнах: `h3` или `.sect` — мелкие прописные серые, 12 px сверху, 4 px снизу. В справке — обычный жирный.
- Кнопки действий стоят ровными колонками на всю ширину окна, а не россыпью разной ширины: длинная кнопка — на всю строку.
- Синий — только главное действие окна и выбранное (язык «Синька»).

## Полосы прокрутки

- Окно прокручивает только своё содержимое (`.pane`), и только по высоте; по ширине содержимое ужимается (`min-width: 0`).
- Рамка окна — `outline` внутрь, а не `border`: рамка не добавляет к размеру, который dockview отдаёт окну, и полос «на 2 px» нет.
- Полосы тонкие, в цвет темы. Проверять скриншотом в Chromium с видимыми полосами: по умолчанию headless их прячет,
  запуск — `ignoreDefaultArgs: ['--hide-scrollbars']`.

## Окна

- Вкладку тянут, чтобы переставить окно; к краю — встроить, на карту — сделать плавающим. Место, куда встанет окно, подсвечено синим.
- Плавающее окно двигают за узкую полосу с точками над вкладками (dockview `floatingGroupDragHandle: 'titlebar'`), Shift + полоса — встроить обратно.
- Крестик — только у выбранной вкладки; у остальных его нет, чтобы щелчок по короткой вкладке не закрывал окно.
- Ширины по умолчанию такие, чтобы на экране 1280 все вкладки группы помещались без стрелки «ещё» (`sizes()` в `App.vue`).

## Строка состояния

- Сообщение — слева, в свободной части: появляясь и исчезая, оно не двигает слой, координаты и масштаб справа.
- Координаты и масштаб — цифрами одной ширины, поле масштаба всегда в рамке (его можно править).
