# Как писать код и документы (пишется вручную; править при смене соглашений)

Для человека и ИИ-агента, который впервые открыл репозиторий. Что где лежит — [files.md](files.md); как устроена программа — [architecture.md](architecture.md);
пошаговые рецепты (добавить источник, маршрут, лист альбома, подпись, модуль, тест) — [howto.md](howto.md).

## В каком порядке читать код

1. [architecture.md](architecture.md) — части программы и путь данных от портала до листа.
2. [modules.md](modules.md) — каждый файл одной строкой (его заголовок) и список функций; искать файл тут, а не открывать большие целиком.
3. Сервер: заголовок `apps/grado2/server.py` и [api.md](api.md) (маршруты), затем нужный обработчик.
4. Страница: `apps/grado2/web/index.html` (порядок подключения скриптов), затем `app.js`; листы и альбомы — `sheets.js`, `albums.js`.
5. Печать: `apps/grado2/print_io.py` (карта листа) → `album_io.py` (оформление листа) → `core/render/grado_render/` (PDF, SVG, PPTX из одних и тех же операций рисования).
6. Ядро: [core/README.md](../../core/README.md) — семь пакетов, кто кого вызывает.

Большие файлы читают кусками (по номерам строк из `modules.md` или `grep -n`), журнал `docs/grado2-changelog.md` — только верх (80 строк).

## Соглашения по коду

- **Заголовок файла.** Первая строка файла кода (`.py`, `.js`, `.mjs`, `.sh`) — что он делает, одной фразой; ниже, если нужно, кто его вызывает, что читает и пишет, чем проверяется.
  Его печатает [modules.md](modules.md); отсутствие заголовка — ошибка `python3 tools/docs_check.py`. Образец — в `docs/CLAUDE.md`.
- **Комментарий объясняет «почему», не «что»**, и ссылается на источник решения: слово владельца с датой и задачей («владелец 07.10.2026, #47»), правило из `label-rules.md`, номер задачи.
  Так через месяц видно, можно ли это менять.
- **Имена.** Файлы — строчными латиницей; в Python `snake_case`, классы `CamelCase`; в JS функции и переменные `camelCase`, константы `ЗАГЛАВНЫМИ`. Ключ слоя — `источник.имя`
  (`gisogd.admin`, `egko.water`, `nspd.parcels`, `sit.stations`); маршрутизировать по ключу слоя, а не по «первому слою вида» (железное правило 5).
- **Одно место для факта.** Состав листов — в `albums.js` (вики `sheets.md` его выводит), источники — в `server.py` (`sources.md`), правила оформления — в `label-rules.md` (свод `album-rules.md`).
  Не копируйте их в код и в другие документы: ссылайтесь.
- **Страница без сборки.** Сторонние библиотеки лежат в `web/vendor/`; новые зависимости в `core` и `apps/grado2` нельзя. Чистая функция без DOM, которую хочется проверить тестом, —
  маленький модуль (образец `labelfmt.js`, `albumgeo.js`) с тестом под Node.
- **Тексты ошибок сервера — только ASCII**; тексты на экране — по-русски простыми словами, как для градостроителя, не программиста.
- **Версия и журнал.** Меняется программа — `apps/grado2/web/version.json` и запись сверху `docs/grado2-changelog.md` в том же коммите; сообщение коммита `grado2 vX.Y.Z: …`.
  Слияние `main` ↔ `team/t60`: при конфликте версии и журнала записи ветки команды ставятся сверху с очередным номером.

## Тесты

| что | где | как запустить |
|---|---|---|
| Python | `apps/grado2/tests/test_*.py`, `core/*/tests/test_*.py` | `tools/gate.sh` (все) или `python -m pytest -q <папка>` с `PYTHONPATH` из `tools/gate.sh` (pytest — `apps/grado2/requirements-dev.txt`; браузер — Playwright, `(cd tools && npm ci)`) |
| JS без браузера (под Node) | `apps/grado2/tests/*_test.js`, запускаются обёртками `test_*_js.py` | то же; пропускаются, если нет Node |
| браузерные сценарии | `apps/grado2/tests/e2e/scenarios.mjs` (группы `p.group("tNN", …)`), `collab_scenarios.mjs` | `E2E=1 tools/gate.sh`; только группы — `E2E_ONLY=t71,t82` |
| навигация и вики | `tools/docs_check.py`, `tools/wiki.py --check` | входят в `tools/gate.sh` и в CI |
| оформление альбома | `tools/album_check.py` (до / после), `tools/album_lint.py` (PDF) | навык `album-verify`, [../standards/albums/layout-qa.md](../standards/albums/layout-qa.md) |

Браузерный шаг **ждёт появления нужного**, а не «спит» фиксированное время (медленная машина CI иначе даёт случайные красные запуски — задача #40, `RULE` в `docs/team/PROGRESS.md`).
Новое поведение — тест рядом в том же коммите; багфикс — тест, который падал до исправления.

## Документы

- Документ кладут на полку по смыслу, а не в корень `docs/` — [../CLAUDE.md](../CLAUDE.md) (таблица полок), карта — [../INDEX.md](../INDEX.md). Новый `.md` называют в README своей полки.
- Страницы вики с пометкой «генерируется» не правят; они собираются `tools/wiki.py` (хук pre-commit, CI). Новая справка, которую можно вывести из кода, — новая функция в `PAGES` этого скрипта.
- Перенос файла: `git mv`, затем `python3 tools/docs_check.py` — он покажет все битые ссылки и пути.
- Журналы (`grado2-changelog.md`, `team/PROGRESS.md`, `team/DECISIONS.md`) только дописываются сверху.
