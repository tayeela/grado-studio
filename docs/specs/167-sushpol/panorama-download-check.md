# Проверка прямого скачивания панорам

29.10.2026. Код ГРАДО не менялся. Проверка выполнена HTTP-запросами, без браузера и скриншотов.

Протокол сверялся с IPanoramaTileLevel Яндекса и исходниками streetlevel,
commit 9163821f299fba9405ac7ecdfa89b413964a1f8a. Полный пакет streetlevel не устанавливался.
Его зависимости включают дополнительные провайдеры, нативные библиотеки и отдельный сетевой стек;
в плане выбран узкий коннектор на существующих средствах ГРАДО. Код библиотеки не переносился.

## Результаты

- Центр территории Безобразово из сохранённого проекта: HTTP-ответ с JSON status=error, code=404.
  Подтверждено отсутствие найденной панорамы в этой точке, а не во всём районе.
- Контрольная публичная точка 37.62, 55.753: JSON success. Получены реальные Point.coordinates,
  imageId, Origin, размеры тайлов 256 × 256 и уровни 6656 × 3328, 3584 × 1792, 1792 × 896, 512 × 256.
- Ближайшая к центру территории точка на Сипягинском шоссе из сохранённых дорог OSM: HTTP 429.
  Автоматического повтора не было. Выдержана пауза 30 секунд перед проверкой JPEG на отдельном адресе тайлов.
- Два оригинальных JPEG низкого уровня контрольной панорамы скачаны с pano.maps.yandex.net,
  проверены Pillow и соединены в изображение 512 × 256. Изображение просмотрено: содержит панораму,
  без элементов плеера, меню, стрелок навигации и подписей интерфейса.

Материалы опыта: /tmp/grado-team/2026-10-29/panorama-download/.
Визуальный результат — control-panorama-lowres.jpg. Это технический контроль протокола;
его не следует принимать за фото Безобразово или финальный кадр 1500 × 1000.

## Не проверено

Полнота панорам вокруг Безобразово; автоматические восемь точек; итоговая прямолинейная проекция
с правильным азимутом; кадр высокого качества; встраивание в приложение, сохранение и PDF/PPTX.
Проверки этих пунктов обязательны до приёмки реализации.
