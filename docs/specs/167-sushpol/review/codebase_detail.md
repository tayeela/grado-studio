# Stage 9 — Codebase Details

Диапазон 429–833 прочитан полностью. Blocker о ложно описанном существующем механизме не обнаружено.

## K1 — Major — фактический сетевой путь движка (493–505)

`web/sheets.js:657–680` вызывает `loadKeys` из `web/app.js:534–597`. Он формирует `/api/fetch`, обрабатывает `layers/errors`, сливает данные и сохраняет пустое покрытие. Сейчас он не отправляет `runId/requestId`, не принимает верхнеуровневый `acquisition`, а успешно пустую выборку записывает габаритным прямоугольником. `web/app.js` отсутствует в перечне изменений. Одного изменения `ui/src/data.js` недостаточно: альбом работает в старом движке внутри iframe.

Добавить Modify `web/app.js`, определить передачу корреляции и подтверждений, их возврат вызывающему планировщику и атомарное применение с данными; проверить основной путь через iframe.

## K2 — Major — потеря подтверждений на сериализации (499–505)

`web/project.js:57` сериализует фиксированный набор полей слоя; `ui/src/collab.js:43–58,263–268` использует whitelist `DATA_F` без `acquisition`. План этих файлов не определяет расширение контрактов данных. После обмена или сохранения подтверждение может исчезнуть при сохранённой геометрии.

Определить каноническое размещение подтверждений, изменения обоих whitelist; проверить round-trip данных с подтверждением через файл, iframe и hub.

## K3 — Major — контрольная версия shared-проекта (487,504,524)

`server.py:1693–1710` сохраняет локальные версии с ограничением частоты. `POST /api/project` в HUB запрещён (`server.py:2441–2443`), `ui/src/project.js:221` для shared возвращает false. У hub другой механизм: `_commit(..., force_snap=False)`, снимки раз в десять минут; публичный push принудительный снимок не запрашивает (`hub.py:1160–1203`). Hub и API отсутствуют в scope.

Задать отдельный контракт принудительной контрольной версии для local/hub с ожидаемой ревизией и подтверждённым идентификатором восстановления; добавить файлы и тесты. Альтернатива — явно ограничить выпуск локальными проектами.

## K4 — Major — атрибуты фильтра дорог (661–665,761)

`osm.py:_KEEP_TAGS:98–100` отбрасывает `access`, `foot`, `tunnel`, `bridge`, `layer`; `walkGraph` в `web/analysis.js` исключает лишь несколько классов highway. Из слоя нельзя выполнить заявленный фильтр закрытых дорог и автомагистралей без пешеходного доступа. План osm.py касается только подтверждения получения.

Определить теги и приоритеты фильтра, нормализацию, обновление старого кэша, тесты запретов и разрешений.

## K5 — Major — общий срок и пауза источника (685–689,712,759)

`netutil.request` ограничивает отдельные операции и делает до трёх попыток; `_wait:93–109` распознаёт только числовой Retry-After с пределом 30 секунд. Общего дедлайна кадра с gate, тайлами и повторами нет. Gate хранит владельцев очереди, но не общий retryAfterAt. Не определена пауза другой вкладки после 429.

Задать общий дедлайн, хранение cooldown, отсутствующий/датированный Retry-After и отмену; передавать оставшийся бюджет в netutil без второго цикла повторов.

## K6 — Major — выбор правил образования (809–811)

`analysis.js:9–16` содержит московские и федеральные альтернативы: школа 1000/500 м; детсад 300/500 м либо 300 м по СП. Для ЦАО московская школа возвращает null. Фраза SERVICES с учётом округа не выбирает записи, результат для ЦАО/неизвестного округа и источник округа. `sheets.js:278–290` дублирует часть значений.

Закрепить ключи SERVICES, выбор округа и состояние без радиального расчёта; единый источник правил и контрольные случаи.
