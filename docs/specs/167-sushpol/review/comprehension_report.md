What this proposes

Добавить отдельный мытищинский набор, который проводит пользователя от территории и встроенного получения данных до связанных тематических листов, PDF и редактируемого PPTX. Подготовка сохраняет подтверждения покрытия, причины неполноты и ручные правки, продолжается с записанной точки и использует одну версию содержания для обоих форматов. Фотофиксация получает изображения прямым скачиванием панорам; доступность поликлиник отображается согласованными владельцем кругами.

How the existing system works, per this document

ГРАДО уже получает данные через сервер и коннекторы, планирует потребности листов, собирает альбомы и печатает их существующими ядрами. Новый Vue-интерфейс работает со встроенным прежним движком через мост; сохранение проекта охватывает данные альбома и контрольные версии. Однако наличие объектов ещё не подтверждает полноту покрытия и юридических атрибутов, а встроенное получение панорам пока отсутствует: доступны импорт снимков и отдельный инструмент разработчика.
