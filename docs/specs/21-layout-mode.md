# #21. Режим «Вёрстка» — редактор листов как InDesign / PowerPoint

Владелец 06.10.2026: «Нужен полноценный редактор листов как в powerpoint libreoffice keynote или indesign». Интервью:
свой редактор в ГРАДО; в первую очередь — рамки и блоки, текст, подписи на карте, свои элементы; отдельный режим
«Вёрстка» (слева листы, по центру лист, справа свойства). Совет: архитектор (`/tmp/grado-team/2026-10-06/council2/architect.md`),
оформление (`creative.md`, макет `mockups/2026-10-06-layout-mode.png`). Задача GitHub #21.

## Принцип
- Что видно в редакторе — то и печатается: сервер рисует лист (SVG) теми же операциями, что PDF и PPTX
  (`/api/print/svg`), браузер рисует только слой правки поверх (рамки, ручки, направляющие, текстовый курсор).
  Расстановку подписей в браузере не дублировать.
- Развиваем то, что есть: `web/layout.js` + `print_io.apply_edits` + `sheet.edits` / `sheet.items` + `carryHand`.
- Все ручные правки — дельты поверх автоматики: запись есть — «изменено вручную», удалить — «вернуть авто».
  Правки живут в проекте, переживают пересборку альбома (как T86d), попадают и в PDF, и в PPTX с первой версии.
- Объект пропал из данных — правка не теряется молча: список «Потеряли привязку».

## Модель
- `sheet.frames`: только отличия авто-рамок (устойчивые id: `map`, `legend`/`column`, `header`, `callout`, `note`,
  `photos`, `title`, `table:*`) — `{id, rect мм, z, locked, hidden}`; свои элементы — `{id: "u:…", kind: text|shape|arrow|callout|image, rect, style, content}`.
- Подписи на карте: устойчивый id `lbl:<слой>|<id объекта>|<n>`; правка `{dx, dy, angle, text, hidden, size}`;
  применяется в `apply_edits` после автоматической расстановки.
- Текст: операция `textblock` (абзацы и переносы считает одна функция по метрикам шрифтов; PDF/SVG рисуют строки,
  PPTX — одно текстовое поле с абзацами).

## Шаги (каждый: `tools/album_check.py` gol и bez без отличий без правок, E2E-сценарий, PR в team/t60)
1. Устойчивые id подписей и рамок; `sheet.frames` дельтами; без правок вид не меняется.
2. Режим «Вёрстка»: три колонки, выбор / двойной щелчок / Esc, перенос и размер рамок, выравнивание и
   распределение, сетка 5 мм, направляющие, привязка, отмена/повтор, метки «изменено вручную», «Вернуть авто».
3. Подписи на карте: сдвиг, поворот, текст, скрытие, «Вернуть авто», список «Потеряли привязку».
4. Текст на листе: правка в рамке, шрифт (Montserrat, PT Sans), кегль, начертание, выравнивание, интервалы;
   `textblock` в PDF/SVG/PPTX.
5. Свои элементы: надпись, прямоугольник, стрелка (наконечник в бэкендах), выноска, картинка.
6. Позже: таблицы с ручными ячейками, стили абзацев, группировка, мастер-страницы, направляющие с линейки.

## Риски
Карта в PPTX растрируется при очень большом числе фигур — подписи на такой карте в PPTX не правятся; двойной щелчок
в рамке карты — только подписи, кадр карты — отдельной кнопкой; легенда «строится сама» — ручное содержимое только
после «Отвязать»; совместная работа должна сливать `frames` (collab.js).
