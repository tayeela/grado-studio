# Сценарий B: журнал трений

Дата: 2026-09-22. Бета beta.115 → beta.116. Изолированный сервер, Chrome. Тот же участок на
Якиманке (11,48 га) с данными сценария A (12,6 тыс. объектов после загрузки по области).

Шаги: скрыть ЗОУИТ, функциональные зоны и УДС → «Добавить слой» → «Здание» «Жилые дома» →
три дома (16, 9, 9 этажей) → слой «Зоны проекта» → зона на участок → слой «Красные линии
проекта» → линия → ТЭП → альбом.

Итог ТЭП: факт СПП по чертежу 135,7 тыс. м², плотность 25,27 тыс. м²/га при включённой
охранной зоне ОКН (расчётная площадь 5,37 га) — сходится с ручным расчётом по площадям домов.
