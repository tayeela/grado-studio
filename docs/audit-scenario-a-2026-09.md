# Сценарий A: журнал трений

Дата: 2026-09-22. Бета beta.111 → beta.112. Прогон на изолированном сервере (отдельная папка
данных, проект владельца не трогался), Chrome.

Участок: квартал на Якиманке между Большой Якиманкой и Большой Полянкой, от Бродникова до
1-го Хвостова переулка, граница 11,48 га. Источники: OSM дороги и здания, НСПД участки, здания
и ЗОУИТ, ГИС ОГД «01. Функциональные зоны» и «Границы УДС (красные линии)».

Шаги: новый проект → подложка → граница → «Данные по видимой области» → печать A3 1:2000 →
альбом.

| 3 | блокер | Поле `id` из атрибутов ГИС ОГД роняло сборку: «неизвестный атрибут 'id'» (слой служебное имя пропускает, а значение писалось) | Пишутся только колонки, которые слой реально завёл |
| 4 | блокер | Печать и листы альбома вписывали все данные: зона ОКН центра (12 км) давала лист 1:50 000 с участком-точкой, печать 1:2000 — сплошную штриховку без участка | Габариты чертежа — граница территории, если она есть (`project_extent`) |
