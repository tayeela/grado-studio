# T86. Единая логика слоёв по листам (окно «Слои и листы»)

Запрос владельца 06.10.2026: «придумай единую логику для всех листов, группировка слоев по листам и перетаскивание,
все должно быть красиво и интуитивно понятно, думай командой». Совет: product, architect, creative (позиции —
`/tmp/grado-team/2026-10-06/council/*.md`, решение — DECISIONS.md 06.10). Макет: `mockups/2026-10-06-sheet-layers.png`.
Заменяет T85d–f (T85a–c остаются и идут первыми).

## Одна логика для всех листов
- Лист состоит из **ролей** (Участки, ЗОУИТ, Красные линии, Здания, Дороги, Рельс и станции, Вода, Названия улиц,
  Генплан и документы…). Набор ролей листа и их порядок задаёт образец альбома; владелец их не тянет.
- Внутри роли — **очередь источников** (главный, запасные: ЕГКО → Яндекс → OSM). Её можно менять перетаскиванием.
  Автомат выбирает первый источник с покрытием рамки ≥ 90 %; иначе следующий, с жёлтой подписью.
- **Глаз** на строке роли — видимость на этом листе (как заморозка слоя в видовом экране AutoCAD / тема карты QGIS).
- Цвета, толщины и подписи — по `label-rules.md`, в коде; перетаскивание меняет, что включено и откуда взято.

## Окно «Слои и листы»
Одно плавающее окно, три колонки: листы альбома (номер, имя, замок, «не готов» с причиной) → роли выбранного листа
(глаз, роль, источник, полоска покрытия, состояние; раскрывается одна строка с очередью источников) → слои проекта,
сгруппированные по ролям, с номерами листов, где слой используется. На 1280 px банк сворачивается в кнопку.

Перетаскивание:
- слой из банка на лист или на роль — включить (подсветка «Отпустите: включить…»);
- роль с листа на другой лист — перенос, с Alt — копия;
- лист без такой роли отказывает красной подписью простыми словами (текст от образца альбома);
- готовый лист (замок) не принимает и предлагает «Скопировать как рабочий».
Двойной щелчок: лист — открыть на холсте, роль — раскрыть источники, слой банка — показать на холсте.
Клавиатура: стрелки, Пробел (глаз), Enter, Alt+↑↓ (источник выше/ниже), R (вернуть авто), M («Перенести на лист…»),
Tab, Esc. В строке состояния всегда «Что дальше: …».

Ручные правки: синяя метка «изменено вручную» и ссылка «вернуть автоматический выбор». Пересборка альбома меняет
только автоматическое; ручное переносится (carryHand).

## Данные (architect)
`sheet.layout = { groups: [{ id, title, role, items: [{ key, on, style?, only?, src?: [] }] }], hand: {…} }`.
Порядок групп и items = порядок рисования. Стиль на листе — дельта от слоя проекта. Нет `layout` — старое поведение
(keys/styles/only/view); ленивая миграция; старые поля живут один релиз. Шаблон ППТ КРТ даёт начальный layout
(`seedLayout(tpl)`), `conceptSheet` читает layout вместо `PPTKRT_C.keys`. Frozen-листы не трогаются никогда.
Совместная работа: `mergeAlbum` сливает по `group.id` и `item.key`. Выгрузка: объединение включённых ролей,
запасной источник — только если главный не прошёл покрытие.
