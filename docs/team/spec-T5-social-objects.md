# T5. Спецификация: участки социальных объектов в эскизе (нормоконтроль)

Дата 03.10.2026. Автор: нормоконтролёр. Шаг 1 из 2 (DECISIONS 02.10): спецификация и тест без кода посадки. Шаг 2 — T6.
Расчётный пресет: `core/compute/grado_compute/presets/moscow_calc2.json` (методика «Калькулятор 2.0»; ТЭП в
`apps/grado2/server.py` ~стр. 916 считаются по ней). Правила округления владельца: СПП и плотность по СПП — 2 знака, остальное —
3 знака; люди и места — вверх (`ceil`, как в пресете; в `moscow_krt.json` стоит `round` — другая, старая методика, для T6 не берётся).
Решения владельца и команды (DECISIONS 02.10): площадь участка — минимум таблицы «не менее»; школа — один объект; ДОО свыше
350 мест делится; сокращение участка до 10 % не учитывается.

## 3. Правило резервирования в эскизе (для T6)

Для каждого типа: `deficit = max(demand − free, 0)`, где `free` — свободные места, введённые владельцем (по умолчанию 0).
Профицит больше потребности участок не отрицательным не делает.

1. `deficit = 0` — участков нет, ТЭП-строки нулевые.
2. ДОО: `n = ceil(deficit / 350)` участков. Места делятся целыми, больший объект первым: `q = deficit // n`, первые `deficit % n`
   объектов получают `q + 1`. Площадь участка = `places_i · m2(places_i)`, где `m2 = 35` при ≤ 150, иначе 32.
   Сумма площадей участков (в м², до округления) **обязана равняться** `deficit · m2` и при `deficit = demand` — `doo_plot_ha` пресета.
3. Школа: 1 участок, `deficit · m2(deficit)` по ступеням 19 / 16 / 14. Ступень берётся по мощности нового объекта, то есть по
   дефициту, а не по потребности (при потребности 1034 и дефиците 634 ступень 19, не 16).
4. Поликлиника: 1 участок 0,35 га при `deficit > 0`.
5. Площадь участка в га: м² / 10 000, округление 3 знака (half-up) только для показа; суммирование — по м² до округления.

Ограничения места (норма задаёт только их; геометрию выбирает руководитель):
- внутри территории проектирования; вне слоёв запретов/ограничений (`restrict_area`);
- доступность до жилых блоков МКД не больше радиуса из п. 1 (ДОО 300 м, школа 1000 м; ЦАО — 500 м и «в границах ЦАО»); для поликлиники — 20 мин, в метры не переводить без решения;
- минимальная форма или размер стороны участка в 2151-ПП / 2150-ПП не заданы. Для поликлиники сноска 2150-ПП допускает меньший
  участок в стеснённых условиях при трёх условиях: противопожарная безопасность, приобъектная стоянка в границах участка или
  рядом, возможность организации строительства (в эскизе минимум не уменьшаем, берём 0,35 га);
- инсоляция в этих актах не нормируется; СанПиН 1.2.3685-21 и СП 251/252.1325800.2016 текстов в базе нет — не проверено.

## 4. Контрольный пример (fixture)

Территория 20 га, `restrict_area = 0`, `ratio_zh = 100`, `nonres_part = 6`, `spp_low_in = 0`, зона 2 (допущение, см. п. 5).
Основной вариант **B**: СПП 450 тыс. м² (плотность 22,5). Вариант **A**: СПП 150 тыс. м² (плотность 7,5), зона 1 — одиночные объекты.
Пресет посчитан двигателем и проверен вручную; тест — `core/compute/tests/test_social_fixture.py`.

### 4.3 Влияние на ТЭП (ожидаемое поведение, не проектируем)
- `population`, `flats`, `spp`, `spp_res_living`, `density_spp`, `density_np` не меняются: участки лежат внутри `calc_area`, в `restrict_area` не входят.
- `density_mkd_plots = spp_mkd / mkd_plots` растёт, если участки МКД уменьшаются на площадь социальных участков (метрика берёт площадь участков МКД из эскиза).
- Зелёная норма, баланс территории и озеленение ДОО/школ: учёт социальных участков в них не проверен — не проверено, нужен ответ архитектора.
