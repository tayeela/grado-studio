# Шаблоны заданий команды

Руководитель цикла собирает задание подагенту из шаблона: подставляет `{…}` и ничего не пересказывает из больших
файлов — даёт ссылки на страницы вики. Шаблоны короткие нарочно: каждое слово задания — токены каждого хода агента.

`implement.md` устроен как подробное ТЗ (по образцу промпта Nate Parrott, Anthropic, 09.10.2026): разделы в тегах —
цель (чем результат является и чем нет), окружение, архитектура, модель данных, фаза 1 (всё проверить до фазы 2), фаза 2,
вне объёма, проверка (запустить, а не пересказать), результат («Работает (проверено)» / «Не сделано» / «Известные
ограничения»), источники. Те же разделы — в форме задачи GitHub (`.github/ISSUE_TEMPLATE/task.yml`), так что задача
переносится в задание как есть. Пустой раздел удаляют целиком, а не оставляют с заглушкой.

| шаблон | когда |
|---|---|
| implement.md | правка программы одной ролью (разделы — как в задаче GitHub «Задача») |
| review.md | ревью архитектора по диффу |
| qa-real-check.md | проверка на живых данных и картинке |
| audit.md | разбор/аудит только чтением |
| album-design-audit.md | аудит оформления готового альбома: плитки страниц, аудиторы Haiku по листам, свод огрехов и правил |
| lead-cycle-start.md | что делает руководитель в начале цикла (для себя) |

Общие запреты (входят в каждый шаблон через «Запреты — prompts/BANS.md»): BANS.md.
