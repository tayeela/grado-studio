# Руководитель: начало цикла (для себя)
1. В ветке команды: `git merge main` (конфликты — руками, версия и журнал — команды сверху), `tools/gate.sh`.
2. Прочитать `docs/wiki/team.md` (не BOARD и PROGRESS целиком) и непринятые записи `docs/team/OWNER.md`.
3. Записать решение владельца в правила (`label-rules.md`) раньше кода.
4. Задачи — по шаблону implement.md; не больше трёх агентов сразу; у двух агентов не бывает общих файлов.
5. Приёмка: review.md + `E2E=1 tools/gate.sh` + живая проверка (qa-real-check.md или сам) → коммит `grado2 vX.Y.Z` в
   ветке, BOARD «Готово к выкладке», запись цикла в PROGRESS.md. Вики обновится сама.
6. Сессия может оборваться: коммит после каждой принятой задачи, агенты пишут ход в /tmp/grado-team/<дата>/.
