# Инвентарь настраиваемости: что пользователь v2 менять не может

Дата: 2026-09-22. Интерфейс: `apps/studio/web/v2` (beta.108). Критерий из плана аудита:
всё, что определяет вид результата, задаётся в интерфейсе без правки JSON и кода.

Статусы: **зашито** — изменить можно только в коде; **частично** — бэкенд принимает параметр,
в v2 ручки нет (либо ручка есть в бете); **настраивается** — есть в v2.

Вес: **тормоз** — мешает в каждом проекте; **шероховатость** — редко; **не сейчас** — вне
критерия ежедневной работы.

## 1. Слои и объекты

| Что | Статус | Где зашито | Вес |
|---|---|---|---|
| Набор слоёв и полок (25 штук) | зашито | `v2/store.js` `LAYERS`; в бете — «Типы слоёв» и «Новый слой» | тормоз |
| Слой, в который попадает начерченная линия (всегда «Красные линии»), точка (всегда «Соцобъекты») | зашито | `v2/shell.js` `runCommand`, `canvas.js:388` | тормоз |
| Атрибуты объекта (этажность, назначение, подпись) | зашито | в v2 нет панели свойств; без этажности здание выпадает из факта СПП | тормоз |
| Переименование, удаление, порядок слоёв | зашито | v2 показывает видимость и захват | тормоз |
| Свой слой под данные, которых нет в списке | частично | бэкенд создаёт `source.*` на лету, пользователь — нет | шероховатость |

## Итог

Блокер один: **в v2 нет автосохранения**. С ним нельзя начинать сценарий A на реальной территории.

Тормозы по частоте в работе:
1. Нет панели свойств объекта — этажность и атрибуты не задать, ТЭП по факту не считается.
2. Оформление слоёв и подписи — только через командную строку по id, списка знаков нет.
3. Начерченная линия всегда уходит в «Красные линии», точка — в «Соцобъекты».
4. Штамп и титул зашиты («ГРАДО», «АГК», «Москва / 2026»), шифр и объект пустые.
5. Состав альбома и формат листа не выбираются, хотя бэкенд умеет.
6. Параметры ТЭП не задать, пресет один.
7. Набор слоёв и источников фиксирован.

Почти всё «частично» — бэкенд и бета это умеют. Значит работа по v2 — перенос ручек, а не новая
логика. Порядок переноса определяют сценарии этапа 2, но автосохранение — до них.
