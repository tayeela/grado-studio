Корневые сертификаты НУЦ Минцифры для НСПД (nspd.gov.ru).

Сайт nspd.gov.ru подписан «Russian Trusted Root CA», которого нет в certifi.
Без него выгрузка НСПД не запускается (проверка сертификата не отключается).

Что сделать: скачайте с сайта Госуслуг (gu-st.ru) два файла
    russian_trusted_root_ca_pem.crt
    russian_trusted_sub_ca_pem.crt
и положите их в эту папку либо в ~/.grado2/ca/ (второй вариант надёжнее:
папка не зависит от обновления программы). Можно также указать путь к
файлу PEM в переменной окружения GRADO_NSPD_CA.

Файлы сертификатов в репозиторий не входят. Проверять отпечатки скачанных
файлов стоит по официальной странице Госуслуг.
