# Для ИИ-агентов

Любой агент (Claude Code, Codex, Cursor и другие) начинает здесь. Главный файл правил — [CLAUDE.md](CLAUDE.md); он короткий, читайте его целиком.

## С чего начать

1. [CLAUDE.md](CLAUDE.md) — правила репозитория и железные правила.
2. [INDEX.md](INDEX.md) — карта папок: что где лежит. У каждой папки верхнего уровня есть свой `README.md` (у `docs/` — `INDEX.md`).
3. [docs/wiki/files.md](docs/wiki/files.md) — вопрос → файл; [docs/wiki/INDEX.md](docs/wiki/INDEX.md) — страницы вики (большая часть собирается из кода сама).
4. Работа с альбомом ППТ КРТ — сначала [docs/wiki/album-rules.md](docs/wiki/album-rules.md); слова и сокращения владельца — [docs/wiki/glossary.md](docs/wiki/glossary.md).
5. Как писать код и документы — [docs/CLAUDE.md](docs/CLAUDE.md) и [docs/wiki/conventions.md](docs/wiki/conventions.md); пошаговые рецепты (источник данных, маршрут, лист, подпись, модуль, тест) — [docs/wiki/howto.md](docs/wiki/howto.md).

## Команды

| что | команда |
|---|---|
| все проверки перед коммитом | `tools/gate.sh` (`E2E=1 tools/gate.sh` — плюс браузерные сценарии) |
| вики совпадает с кодом | `python3 tools/wiki.py` (пересобрать), `python3 tools/wiki.py --check` |
| навигация: ссылки, пути, полки, заголовки файлов | `python3 tools/docs_check.py` |
| запуск программы | `python3 apps/grado2/server.py` (порт 8650 — это рабочая программа владельца, тестируйте на другом порту) |

## Порядок работы

- Задачи и слова владельца — GitHub Issues; работа — ветка `task/<номер>-<имя>` и PR в `team/t60`; в `main` — только по слову владельца «выкладывай».
- Владелец — градостроитель, не программист: отвечайте по-русски, простыми словами, без эмодзи, описывайте то, что видно на экране.
- Проект владельца (`~/Documents/ГРАДО 2`) и порт 8650 не трогать; кэш `~/.grado2/cache` не удалять без вопроса.
- Новое замечание владельца по альбому — сначала правило, потом код, потом настоящая пересборка на копии проекта и сравнение страниц (навык `album-verify`).

## Сборка презентации через MCP

Если подключён сервер `grado`, начинайте с `grado_health`, `grado_list_projects` и `grado_project_status`. Слои получает сама программа. Сохраняйте UUID команды старта и проверяйте статус/причины неполноты. PDF и PPTX выгружаются с одним run_id. Черновик не называйте готовым комплектом. [Подключение и инструменты](docs/guides/grado-mcp.md).
